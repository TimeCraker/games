# 街机小游戏设计档案

本文件合并了《星域突围》《弹珠风暴》两款重制小游戏原来的四份白皮书和 UI / 美术规格（2026-10-23 合并，原文可在 git 历史查到）。两款都已落地；下面只保留**仍约束后续改动的定案、红线和验收口径**，具体参数以代码为准。代码注释里的「白皮书 §N」「美术圣经 §N」「ui-spec §N」指合并前的原文档章节。

- 全站 UI 工艺规则：[ui-rules.md](ui-rules.md)
- 品牌色与动效 token：[STYLE.md](../../docs/STYLE.md) §5，单一真源是 `app/globals.css`
- 游戏中英文名、分类、副色：`src/components/arcade/brand.ts`（禁止在别处硬写游戏名）

## 0. 共享层与共同红线

- **共享组件**：
  - 弹层统一走 `ArcadeEntry`；结算统一走 `ArcadeResult`，它内部调用 `records.ts` 的 `submitRecord`。
  - 分数记录只存在 `asternova.arcade.v1`（best / plays / lastRoundId），不要各游戏自己写 localStorage。
  - 细则见 ui-rules.md §4、§10、§13。
- **品牌红线**：
  - 冷中性黑底 + 单一琥珀金主色，每个游戏一个低饱和副色（`--arcade-<slug>`）。
  - 禁紫、品红、高饱和青蓝。验收：`grep -E 'violet|fuchsia|purple|indigo|pink-[0-9]|cyan-[0-9]'` 在 `src/components` 命中为 0。
- **游戏内美术全部程序化**：用 Pixi Graphics 代码绘制，不引外部位图。位图只用于大厅 key art（`public/art/arcade/`，来源与署名见同目录 `CREDITS.md`，由 `scripts/fetch-arcade-art.mjs` 生成）。
- **改动边界**：重做一个游戏时只动它自己的目录和路由。大厅框架、`records.ts` 数据结构、其它游戏的副色不动；`brand.ts` 只改本游戏那一项。
- **验收**：
  - 桌面 1440×900 和真机移动 UA（390×844，必须同时改 UA，不能只改视口尺寸）两端都要截图。
  - 要连拍两帧，证明画面在持续演进。
  - 制作人看图说"好看且可读"才算过。build、lint 通过不等于能玩（见 ui-rules.md §14）。
- **音频**：BGM 放 `public/audio/games/<slug>/`，首页与大厅音乐在 `public/audio/home/`、`lobby/`，UI 音效在 `public/audio/sfx/`。开始按钮在 BGM 就绪前不放行。

## 1. 星域突围（Nebula Survivor）

- **路由与代码**：`/nebula-survivor`。代码在 `src/components/nebula-survivor/`，分为 `content/`（数据）、`sim/`（纯 TS 固定步长模拟，带 vitest）、`render/`（Pixi）、`ui/`（React HUD），入口是 `NebulaGame.tsx`。
- **品类**：俯视角存活类肉鸽，一局 4–8 分钟。自动索敌，玩家只管走位、放 E 技、合成构筑。**没有"升级三选一"**，主轴是捡 / 买武器 + 三合一升星。
- **玩家单位**：**舰装少女**，由人形本体和两侧可换装的舰装挂架组成，不叫"战舰"。统一用语：
  - **机型**：5 种装配方案
  - **舰装**：武器和挂架
  - **机库**：局外界面
- **机型**（5 个）：每个机型 = 数值倾向 + 3 把专属舰装 + 1 个专属 E 技，不新增武器属性维度。

  | 机型 | 倾向 | E 技 |
  |---|---|---|
  | 近卫型 | 高攻高防 | 闪现 |
  | 炮击型 | 高攻低防 | 尾焰疾驰 |
  | 引力型 | 高法低物防 | 护盾 |
  | 重装型 | 超高防、攻低 | 装甲充能 |
  | 机动型 | 高移速高爆、脆 | 量子回跳 |

- **武器**：
  - 共 10 把，分三系：近战 4、远程 3、法术 3。远程是"子弹飞过去"，法术是"在地上放一个场"。
  - 单局最多持有 3 把。
  - 升星有三条路：3 个同名同星合成 +1 星，花金币直升 1 星，或在商店直接买。
  - 升星只加伤害、射程、范围，**不加随机词条**。单局可升到 5★。
- **品级色**：

  | 星级 | 1★ | 2★ | 3★ | 4★ | 5★ |
  |---|---|---|---|---|---|
  | token | `--paper` | `--arcade-nebula` 青柠苔绿 | `--arcade-shoot` 钢青 | `--amber-500` | `--signal-red` |
  | 工艺 | 细边 | 细边 + 底色 | 加内发光 | 粗边 + 辉光 | 粗边 + 辉光 + 流光 |

  - 档次靠工艺单调递增来读，不靠色相。
  - **品级色只允许出现在武器槽和武器卡上**，UI 强调色（琥珀）不进这个区域。
- **E 技**：一律走位或生存向，不做输出型。
- **地图**：有限竞技场 + 墙 / 掩体 / 通道，主题是废弃矿星和轨道站残骸。
- **局外养成**：在机库界面里，它是局内的一个阶段（phase），不新开路由。
  - 金币用来买武器、升 E 技；经验用来升攻击、防御、法术基础值；职业全部解锁。
  - 存档在 `asternova.nebula.v1`（`save.ts`），与 `arcade.v1` 分开；坏字段逐个丢弃，不让整份存档作废。
- **界面**：
  - 单路由 phase 状态机：briefing → hangar → run（含商店、暂停）→ over → hangar。
  - 进场简报（briefing）**不传 `onRequestClose`**，必须显式点"开始任务"。
  - **全屏自适应，绝不放进 `transform: scale()` 容器**（旧版在真机上被缩成 390×210 的条带，字号只剩 4.6px，见 ui-rules.md §15）。
  - HUD 分区：左上生存数据、右上系统键、雷达（敌方按方位显示光点）、底部武器槽（品级、星数、`n/3` 合成刻痕）、右下 E 技冷却环；摇杆只在触屏显示。
  - HUD 文字 ≥12px，关键按钮命中区 ≥44px。
- **性能与测试**：峰值 3000 敌 + 400 子弹时移动端 60fps；同种子 + 同输入流回放，快照 hash 一致。
- **未定**：具体数值（定价、成长曲线）、Boss 机制细化、难度层级。

## 2. 弹珠风暴（Shoot Them All）

- **路由与代码**：`/shoot-them-all`。代码在 `src/components/shoot-them-all/`：
  - `engine/`：matter-js 物理和关卡数据 `content/levels.ts`
  - `render/`：Pixi
  - `ui/`：React
  - 画布色板常量在 `constants.ts`
- **玩法**：关卡制弹珠消乐，**不是肉鸽**（旧版的肉鸽节点、敌人回合、Boss、遗物方案已作废）。
  - 每关有目标分和限定球数，玩家自由选球发射，球打完时分数达标就过关，否则重试。
  - 星级按剩余球数算：剩 ≥2 个 3★，剩 1 个 2★，剩 0 个 1★。
  - 现有 10 关。
- **球种**：

  | 球 | 效果 |
  |---|---|
  | 标准弹 | 基础弹跳 |
  | 爆裂弹 | 命中炸一圈，半径约 90 |
  | 穿透弹 | 穿过钉阵不衰减 |
  | 重弹 | 可击碎石头、冰障碍 |

  分裂弹、炸弹钉只预留了接口，没做。
- **物理**：restitution 0.55；轨迹预测线只画首碰点和首碰后的一次弹射。
  - ⚠️ matter-js 刚体要先建成动态体，再 `Body.setStatic(true)`，否则会卡死（见 ui-rules.md §14）。
- **美术母题**："深空观星台"：黄铜星象仪发射器、翠玉晶体钉、琥珀陨星球、冷黑深空底片。不要霓虹赛博，不要卡通糖果。
- **两层色板**：
  - 画布只用 `constants.ts` 的 `PALETTE` 和 `BG_GRADIENT`，可以派生明暗，不能漂移色相。界面只用 `globals.css` 现有 token，不新造颜色。
  - 翠玉 `jade` 只用于画布里的晶体。钢青 `--arcade-shoot` 只用于界面的选中、焦点态，不进画布。同屏时琥珀永远是第一视觉。
- **布局**：逻辑画布 720×1280，竖屏单手优先，等比缩放。
  - 两侧留边用 `.arcade-letterbox`。
  - 缩放容器里只放非交互 HUD，字号按 2 倍余量给（逻辑 24–40 → 真实 12–20px）。
  - 触控目标真实尺寸 ≥44px。
- **性能预算**：
  - 常驻粒子 ≤120；峰值 ≤200，并在 400ms 内回落；单帧新增粒子 ≤40。
  - 发光用预烘焙径向贴图，**禁止每帧 BlurFilter**。
  - 屏幕震动只平移不旋转；`prefers-reduced-motion` 时取消震动、停掉星尘漂移、星级直接显示终态。
- **未定**：BGM 是否重做、数值调优、关卡扩展。
