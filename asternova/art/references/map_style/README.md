## 二、 提炼总结：指导建模与材质制作的五大金律

1. **地板材质（Floor Pavement）**：
   * 告别纯平灰块，必须呈现**大型深浅拼缝石砖、盲道凸点砖、沥青微裂纹修补块、铸铁排水箅子与下水井盖**。
   * 粗糙度贴图（Roughness）控制地面微反光，晴天下有自然的天空倒影。
2. **建筑与油漆装饰（Building & Paint Deco）**：
   * 墙面使用干净现代的防水瓷砖（米白/浅灰）与浅黄色灰泥，边缘有轻微风化倒角（Bevel）。
   * 门窗必须具有 **15~20cm 真实内凹进深**，搭配铝合金滑轨、深色窗台雨檐与防盗金属网栅。
3. **电线杆与空中天网（Poles & Overhead Cables）**：
   * 水泥电线杆必须附带**灰色变压器铁箱、绝缘瓷瓶、监控探头与悬挂警示标牌**。
   * 电缆必须具备自然下垂的悬链线弧度（Catenary curve），交错穿行在屋顶与路口之间。
4. **高频生活微道具（Street Props Ecosystem）**：
   * 交通载具：橙色复古踏板摩托车（Vespa）、自行车、带警示灯的工业小推车。
   * 街道设施：黄色防撞警示锥、黑色垃圾袋、分类果皮箱、红绿灯过街按钮箱、折叠木椅与咖啡遮阳伞。
5. **渲染风格定位（Render Styling）**：
   * 追求 **“2渲染3的次世代清透写实”** —— 模型具备扎实的 3D 物理结构和真实的 PBR 微表面，但光照通透不脏乱，色调清澈分明，彻底杜绝廉价塑料玩具感，同时避免过度杂乱导致的玩家眩晕（抗 3D 眩晕）。
