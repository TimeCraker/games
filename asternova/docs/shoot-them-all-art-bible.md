## 1. 母题与气质

**一句话定调**：**深空观星台** —— 黄铜星象仪发射器向翠玉晶簇与琥珀陨星构成的星图开火，冷黑深空里只有仪器的微光与晶体的切面在说话。

气质对标：**「天文仪器 × 晶体矿脉」的克制高级感**（终末地式工业精密 + 矿石切面质感），不是霓虹赛博，不是卡通糖果。

**像什么**：
1. 像一台被精心保养的**黄铜星象仪 / 赤道仪**：刻度、倒角、指针、蓄力光环，一切装饰都像仪器零件。
2. 像暗室里打光的**翠玉晶簇标本**：低饱和、切面高光、边缘一圈冷灰描边。
3. 像天文台长曝光的**深空底片**：冷黑、细星尘、暗角、极轻颗粒，画面 90% 是安静的黑。

**坚决不像什么**：
1. **不是霓虹赛博**：禁紫 / 品红 / 高饱和青蓝，禁多色渐变发光管、禁外发光描边泛滥（品牌红线，白皮书 §8）。
2. **不是卡通糖果**：禁圆润 Q 弹的高饱和色块、禁表情化拟人、禁厚重黑描边漫画感。
3. **不是「空画布 + 几颗六边形」**（白皮书 §8 点名的现状病）：任何一屏截图必须一眼读出「这是个做完的游戏」——有背景层、有 HUD、有质感、有反馈。

## 2. 色彩系统

### 2.1 两层分工总表

| 层 | 载体 | 色板来源 | 用途 | 禁止 |
|---|---|---|---|---|
| **画布层**（Pixi） | 球 / 钉 / 障碍 / 轨迹 / 发射器 / 特效 / 背景 | `constants.ts` 的 `PALETTE` 与 `BG_GRADIENT`（下表 2.2） | 游戏世界内一切像素 | 禁止引入 PALETTE 之外的新色相；派生明暗可以，色相漂移不行 |
| **界面层**（CSS / React） | HUD / 选关 / 球托 / 暂停 / 结算 / 提示条 | `globals.css` 的 `--hud-*` / `--amber-*` / `--ink-*` / `--fog-*` / `--signal-*` / `--glass-*` 与 `--arcade-shoot` | 游戏外壳与浮层 UI | 禁止在 globals.css 新增颜色令牌；禁用 Tailwind 默认紫/蓝/粉系 |

### 2.4 两个「副色」的边界（重要，防打架）

- **翠玉 `jade` 是世界内语义色**：只用于画布里的晶体（普通钉、冰障碍折射底色、晶体碎屑）。UI 里出现「晶体」图例 / 球种说明插画时，取色仍是 `PALETTE.jade`（实现上 `import { PALETTE }` 或写同值 `#7FB39E`，**不在 globals.css 加 `--jade`**）。
- **`--arcade-accent`（钢青）是壳层点缀色**：只用于界面层的选中态 / 焦点态 / Spotlight 边缘光 / Dock 选中环 / BrandMark。**不进画布**，不画球和钉。
- 同屏相遇时琥珀永远是第一视觉；翠玉与钢青都退居第二层，且单处出现面积不超过对应控件的描边宽度（≤2px）或一枚 8px 图标。

## 3. 游戏内元素视觉规格

坐标系：**逻辑画布 720×1280**（`WIDTH`/`HEIGHT`，纵向竖屏），单位均为逻辑 px。物理常量以 `constants.ts` 现值为准（`ballRadius 9`、`pegRadius 10`、`launchAnchor {x:360, y:70}`、`±78°`、`restitution 0.55`）；下文尺寸相对这些常量给出，引擎若调半径，光晕 / 拖尾按比例跟随。

### 3.1 球（陨星）×4

共同规则：球体 = 主色圆 + 1.5px 描边 + 左上高光点；外扩光晕 = 预烘焙径向渐变贴图（半径 ×2.2 球径，中心 alpha 25% → 0），**禁止每帧 blur filter**。

| 球 | 形态 | 光晕 | 拖尾 | 命中特效差异 |
|---|---|---|---|---|
| **标准弹** `standard` | 标准陨星圆（r=9），表面 2 道极浅弧线纹理 `brass` @25% | `amber` 柔光 | 8 点渐隐残影（间距 6px，alpha 0.5→0，寿命 140ms） | 标准击钉闪光（见 3.7） |
| **爆裂弹** `blast` | 亮一档（`amberBright`），核外一圈 `brass` 暗环，像待爆的火成岩 | `amberBright` 比标准亮 20% | 拖尾尾端带 2–3 粒火星（寿命 200ms） | **爆裂 = 冲击环 + 火花**：双环冲击波（r 20→90，见 3.7）+ 16 粒放射火花 |
| **穿透弹** `pierce` | 最亮最「轻」（`amberPale`），体态略扁（scaleX 1.12）表现速度感 | `amberPale` 窄光 | **残影线**：沿速度方向 24px 拉长的线段（`amberPale` @40%，宽 3px），不掉点 | 命中不减速、无击退闪光，只在穿过的钉上留 0.8s 淡金残痕 |
| **重弹** `heavy` | 黄铜体（`brass`），直径 +2px（视觉重量），赤道一圈 `--ink-500` 金属环 | `amber` 暗光（更收敛，靠重量说话） | 无拖尾，改为每 3 步掉 1 粒重尘（寿命 300ms，垂直下落） | **震动 + 碎屑**：命中即触发屏幕震动（见 3.8）+ 6 粒碎屑（见 3.7 碎屑参数） |

### 3.2 钉 ×3

| 钉 | 几何 | 发光 | 命中反馈 |
|---|---|---|---|
| **普通晶体钉** `crystal` | 正六边形切面宝石，外接圆 r=10（= `pegRadius`）；内部分 3 个菱形切面：左上 `jadeLight` @100%、右下 `jade` @80%、底部 `jade` @60% | 外扩 4px 翠玉柔光（`jade` @18%），常亮不呼吸 | 击中：整体闪白 `jadeLight` 80ms + scale 1→1.18→1（spring）；清掉时碎成 3 块菱形碎屑 |
| **高分共鸣钉** `resonance`（150 分，白皮书 §5 关 2 引入） | 与晶体钉同六边形，但切面换琥珀；中心多一颗 4 芒星（`amberPale`，臂长 5px） | 琥珀呼吸环：r 12→16 循环，2.6s（`--duration-ambient` 节奏），alpha 30%→8% | 击中：星芒爆亮 120ms + 分数数字用琥珀色加粗跳出（普通钉用冷灰） |
| **炸弹钉** `bomb`（**预留**，后续关卡） | 六边形换圆角方形（12×12），中心圆 r=4 `danger`，四角 1px 警示刻度 | 危险红脉冲 2s（alpha 25%→10%），克制、不闪爆 | 引爆 = 迷你冲击环（r 20→55）+ 红色火花 8 粒；预留接口，首发不实现 |

钉的通用：常驻态**不闪烁不跳动**（母题是标本不是霓虹），只有共鸣钉呼吸环是唯一常驻循环动效。

### 3.3 障碍 ×2

| 障碍 | 完好态 | 破损态 | 击碎 |
|---|---|---|---|
| **石头** `rock` | 不规则 6–8 边形（外接 r 28–40），双面切色：主面 `--ink-600`、背光面 `--ink-500`；边缘 3–4 处小缺口（1px `--fog-400` 断续） | 被重弹击一次后：表面裂纹（2 条折线，`--fog-400` @40%，宽 1px）+ 缺口加深 | 裂成 4–6 块碎屑（同色多边形，重力 0.15、自转、寿命 500ms） |
| **冰** `ice` | 半透明棱柱（六边或八边），底色 `--fog-100` @22% 叠 `jadeLight` @18%；内部 2–3 条折射线（`sparkWhite` @12%）；描边 `jadeLight` @60% | 裂纹同石头，但裂纹发白（`sparkWhite` @35%），像冰面应力纹 | 碎成 5–7 片三角薄片 + 6 粒闪光（`sparkWhite`，寿命 240ms） |

只碎不裂的「一击粉碎」留给重弹；普通 / 穿透弹打在障碍上：**无裂纹、只有 1px 轻微位移震颤（0.3px，80ms）**，明确「打不动」的手感。

### 3.4 轨迹预测线

- **形态**：虚线，节奏 **dash 6px / gap 8px**，宽 2px，色 `amber` @55%。
- **范围**：首碰点 + 首碰后 1 次弹射段（白皮书 §7 已落地逻辑）；第二段 alpha 降到 25% 表示置信度衰减。
- **首碰标记圈**：r=14 空心圆，`amberBright` 1.5px，内含 4 个 3px 刻度齿（赤道仪语言）；出现时 120ms scale 0.6→1 pop。
- **虚线呼吸**（可选，默认开）：dash 相位每 2s 推进 14px（刚好一个 dash+gap 周期），`prefers-reduced-motion` 时停。
- **禁**：不画全段实线、不做发光拖尾、不预测二次以上弹射（会变面条）。

位置：炮管枢轴 = `launchAnchor (360, 70)`；与 HUD Dynamic Island **一体化**（见 4.1）：胶囊即仪座，炮管自座底伸出。

        │  2,450 ▏ 3,200      ⚫⚫⚫⚫      ×5 COMBO │
        ╰───────────────┬────────────────────────────╯
                        │ ← 枢轴 (360,70)
                   ╱▔▔▔▔▔╲  ← 炮管（随瞄准旋转 ±78°）
                  ╱  ▱▱▱  ╲

                    ◇◇◇     ← 炮口晶石（amber 菱形）

|---|---|
| 基座（岛内） | 已由胶囊承担；胶囊底部探出 12px 梯形黄铜接口（`brass`，上宽 48 下宽 36） |

| 刻度弧 | 半径 56px 的细弧，`--fog-400` @30%，每 10° 一根 4px 刻度、每 30° 一根 7px 主刻度（赤道仪语言，与 `.reticle-ring` 同源） |

### 3.6 背景（L0–L3 四层）

| 层 | 内容 | 参数 |
|---|---|---|
| L0 底色 | `BG_GRADIENT` 三段垂直渐变 | 上 `0x08090d` → 中 `0x0b0d12` → 下 `0x050608`（重心压底） |
| L1 星尘 | 60–90 颗细星点 | 1–2px 圆点，色 `--fog-400` / `amberPale` 二选一，alpha 20–45%；缓慢漂移 ≤4px/s（两层视差：近层 4px/s、远层 1.5px/s）；**全屏最多 3 颗**允许 2.4s 呼吸明灭 |
| L2 星云霾 | 2 团极淡径向渐变 | `--ink-700` @8%，半径 280 / 420，固定不滚动 |
| L3 质感 | 暗角 + 颗粒 | 暗角：径向从中心到四角变暗 35%（透明黑）；颗粒：同 `.hud-grain` 的 feTurbulence 配方，opacity 0.03（`--grain-opacity`） |

扫描线**只上界面层**（HUD 面板 / 结算 cinematic），**不上游戏画布**——画布保持底片般干净。

### 3.7 命中特效与粒子（数量 / 寿命 / 缓动）

| 特效 | 触发 | 参数 |
|---|---|---|
| 击钉闪光 | 任意球命中钉 | 钉体闪 80ms + scale pop（spring）；外扩 1px 白环 r 10→18，200ms easeOutCubic |
| **爆裂冲击环**（blast） | 爆裂弹命中 | 双环：外环 2px `amberPale`→`amber` r 20→90（半径=白皮书 ~90px）、320ms easeOutCubic；内环 1px `sparkWhite` r 20→50、200ms；芯 `danger` @40% 仅前 80ms |
| **穿透残影线**（pierce） | 穿透弹穿过钉 | 钉上淡金残痕 24px×2px @35%，0.8s 线性淡出；球本体拖尾已在 3.1 定义 |
| **重弹震动 + 碎屑**（heavy） | 重弹命中钉/障碍 | 屏幕震动（3.8）+ 碎屑 6 粒：三角 3–5px，`brass`/`jade` 随目标材质，初速 2–4px/step、重力 0.15、自转 ±180°/s、寿命 500ms easeOut |
| 火花 | 爆裂 16 粒 / 命中 6–10 粒 | 2–4px 圆点，色 `amber`/`amberPale`，寿命 280ms，easeOutCubic，尺寸线性归零 |
| 分数跳字 | 每次得分 | 「+N」上浮 40px、淡出 320ms（`--ease-instrument`）；普通钉用 `--hud-text-dim`、共鸣钉用 `--hud-accent-bright` |
| 清场收尾 | 过关瞬间 | 剩余钉按 30ms 间隔 stagger 自爆（各自 200ms 小爆闪），形成「连锁点亮」 |

**粒子预算**（移动端 60fps 硬顶，§7）：常驻粒子 ≤120，爆炸峰值 ≤200 且必须在 400ms 内回落到 120 以下；单帧新增 ≤40。

### 3.8 屏幕震动

- **触发**：爆裂弹爆炸（amp 6px）、重弹命中（amp 5px）、过关清场（amp 4px，横向为主）。标准 / 穿透弹**不震**。
- **参数**：随机方向位移，振幅逐帧衰减至 0，总时长 300ms；**只平移不旋转**；作用对象 = 画布根容器 transform（不是 CSS）。
- **上限**：同一时刻只取最大振幅叠加，不做叠加累积（防晕）。
- `prefers-reduced-motion`：震幅归零，改为 80ms 全屏亮度 +4% 的轻闪提示。

### 4.3 球托 · Dock Magnification（选球 UI）

底部横排球列（y 1148–1252），**macOS Dock 式距离衰减放大**：

- 槽位基准 72×72，间距 12；居中对齐。
- 缩放：`scale(i) = 1 + 0.35 × falloff(d)`，`falloff = max(0, 1 − d/2)²`，d = 与悬停槽的距离（槽为单位）。即悬停槽 1.35、邻槽 1.09、再邻 1.0。
- 动画只动 `transform: scale()` + `translateY(-6px)`（悬停槽上浮），180ms `--ease-instrument`。
- **当前选中球**：持续高亮——槽位外环 `--arcade-accent` 2px + 底部 2px 琥珀指示条；即使不悬停也保持 1.12 倍。

## 9. 验收清单

对照白皮书 §9.4「像游戏」拆解；验收以**真机 / 真实页面截图**为准，模型口头 PASS 不算。

**母题与气质**
- [ ] 任意一屏截图能说出「深空观星台」：有星象仪、有晶体、有深空底片感
- [ ] 全屏无紫 / 品红 / 高饱和青蓝像素（可用取色器抽查 5 点）
- [ ] 无卡通糖果感、无霓虹外发光描边

**色彩**
- [ ] 画布元素取色 100% 落在 §2.5 表内；UI 元素 100% 落在现有 CSS 令牌
- [ ] 玫翠玉只出现在晶体语义位、钢青只出现在壳层点缀位（无混用）
- [ ] 背景四层齐（渐变 / 星尘 / 霾 / 暗角颗粒）——不再是空画布

**游戏内元素**
- [ ] 4 种球形态 / 光晕 / 拖尾 / 命中特效四者**互不相同且一眼可辨**（爆裂有冲击环、穿透有残影线、重弹有震动碎屑）
- [ ] 晶体钉 / 共鸣钉几何与发光可区分（共鸣钉有星芒 + 呼吸环 + 琥珀色）
- [ ] 轨迹线虚线节奏正确、有首碰标记圈、第二段更淡
- [ ] 星象仪五件套齐全（接口 / 炮管 / 晶石 / 蓄力环 / 刻度弧）
- [ ] 石头哑光、冰半透明折射，二者破损态可见；普通球打障碍「打不动」只有微颤

**界面层**
- [ ] HUD 胶囊含分数 / 目标 / 剩余球三区，连击时展开，过关时展 CLEAR
- [ ] 选关 Bento 网格：featured 当前关 + 卡面四要素（关号 / 名称 / 星级 / 目标分）+ 三态（锁定 / 解锁 / 通关）
- [ ] Spotlight Border 光斑跟随光标（触屏退化为呼吸柔光）
- [ ] Dock 悬停放大衰减正确（1.35 / 1.09 / 1.0），选中球持续高亮，余量角标准确
- [ ] 暂停面板：玻璃 + 内描边 + 斜切，无外发光；三按钮齐全
- [ ] 结算走 ArcadeResult → ResultOverlay：cinematic 扫描线在、星级三颗可数、NEW RECORD 出现在破纪录时、stats 五行读数齐
- [ ] 首关教学提示条按序出现且可自动消失

**动效**
- [ ] 抽查 §5 任 5 条：时长与缓动在规定范围，且只动 transform / opacity
- [ ] `prefers-reduced-motion` 下：无震动、无星尘漂移、星级直出终态

**排版**
- [ ] 数字全是 mono-data 等宽不抖；标题全是 Orbitron；中文无方框缺字
- [ ] HUD 字号按 2 倍余量（真实 12–20px 可读）

**移动端 / 性能**
- [ ] 单手竖屏可完整操作：瞄准 → 发射 → 选球 → 暂停，全程无误触
- [ ] 大钉阵 + 爆裂峰值（200 粒子）帧率稳定 60fps（DevTools performance 抽查 10s）
- [ ] 触控目标 ≥44px 真实像素；安全区无裁切

## 10. 与既有文档的关系

- **白皮书** `shoot-them-all-whitepaper.md`：玩法定稿；其 §8 美术方向与品牌红线是本文档的上位约束；其 §10「美术主题」待定项由本文档 §1 拍板结案。

- **`globals.css` / `ResultOverlay.tsx` / `ArcadeResult.tsx` / `motion.ts`**：界面层令牌与结算组件的唯一来源；本文档只规定「怎么用」，不新增令牌。
- **`STYLE.md`**：AsterNova 3D 资产风格圣经，管 Godot 角色 / 场景管线，与本 H5 小游戏互不覆盖；两者共守 AsterNova 品牌红线（禁紫 / 品红 / 高饱和青蓝）。
