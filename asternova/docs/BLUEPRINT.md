# AsterNova 总蓝图（BLUEPRINT）

> 状态：**v1.0 定稿**（2026-08-30）。本文是 AsterNova 所有开发决策的最高锚点；任何实现与本文冲突时以本文为准，修改本文必须由用户（TimeCraker）拍板。
>
> 配套文档：[architecture.md](architecture.md)（技术定案）· [STYLE.md](STYLE.md)（美术风格圣经）

## 愿景

- **先做出高质量的游戏**，暂不考虑商业化；玩法方向已定案（2026-08-31，见「玩法」节），机制细节随开发由用户主导深化。
- **轻量高性能**：低配设备流畅，高配设备享受更高帧率与更精致画面（三档画质分级，运行时可切；**渲染帧率 120 起步上不封顶**，模拟 60Hz tick 与渲染帧率解耦）。
- **画面走二次元角色渲染**：对标崩铁 / 原神 / 绝区零 / 终末地 / 鸣潮的画风（toon ramp + SDF 面部阴影 + 描边 + 后处理），风格化路线，不做写实。
  - 预期管理：可复制的是**技术管线**；零授权 AI 资产管线的现实上限是"风格统一、干净讨喜的独立游戏二次元画风"，逼近上限靠 STYLE.md 约束 + 用户验收把关。
- **全栈零授权成本**，只用开源 / 免费工具；本机不跑 AI 推理。
- **分工**：用户只负责指挥、设计玩法、审核验收；代码、建模、测试、部署全部由 agent 完成。所有改动必须可验证（测试 / 构建 / 真实运行），渲染与资产先出验证件给用户过目再批量生产。

## 产品形态（2026-08-31 重大定案：单机优先 + 房主联机）

- **一期 = 单机为主的 3D 动作游戏**：游戏本体单机可玩；联机为**房主模式（P2P）**——房主进程即权威端，**2~6 人 PvE 合作**开黑，玩家电脑当服务器。开发者零机房成本；防作弊按好友场景合理松弛。
- **玩法**：3D 自由视角动作（绝区零 / 鸣潮式「3D 世界跑着打架」）+ **Roguelite 单局**；**设计北极星指标**（North Star Metric：一切设计决策对着校准的唯一核心目标）= **爽感与上瘾性**——任何玩法设计先问爽不爽、上不上瘾（机制细节随开发由用户主导定稿）。
- **模拟核心**：GDScript 战斗核心跑在 Godot 进程内（60Hz 固定步长）；单机 = 本地直调，联机 = 房主权威 + 快照广播。
- **Go 后端基建（auth / 网关 / 匹配 / PG / Redis / 60Hz 服务端核心）封存为二期「大型联机游戏」起点资产**（见「二期规划」），一期不部署任何中心服务。
- **三端优先级**：**Steam（Windows exe）首发**；Web = 试玩 demo 引流位；Android 后置（触屏动作适配成本届时评估）。
- **UI 分界**：菜单 / 设置类 = **React**；游戏内 UI（HUD 等）= **Godot**。宿主形态（WebView 嵌入 vs 启动器分离）M3 spike 验证后定。

## 验收节奏

- **agent 日常闭环**：headless 测试（Go 回放 / GdUnit4）+ 截图自检，不事事上抛。
- **用户验收**：每个里程碑交付一键可跑的 demo build，用户只验里程碑件；用户时间优先花在玩法决策与美术验收。
- **性能红线**：tick 预算 16.6ms / GC 停顿 / RTT P95 一律以实测数据为准，不凭感觉换语言换组件；battle tick 热核保持独立模块，性能红线触发才可用 Rust 重写该模块。

## 玩法（2026-08-31 方向定案，机制细节随开发深化）

- **已定**：3D 自由视角动作（绝区零 / 鸣潮式）· **Roguelite 单局**（北极星指标：爽感与上瘾性，一切玩法设计对着它校准——机制届时专门讨论）· **PvE 合作 2~6 人** · 单机为主 + 房主联机。
- **待定**：黄昏樱花商店街定位（倾向：第一块战斗场地，主城后置）· 地图结构（倾向：副本制小场地；连续关卡与开放区域一期不碰）· 敌人阵容 / 成长曲线 / 局外养成——M2 战斗骨架可玩后由用户主导定稿。
- 带宽复核：2~6 人快照广播 ≈ 20~75KB/s 上行（房主），家庭宽带无压力。

## 二期规划（占位）

- **大型联机游戏（中心服务器架构）**：现有 Go backend 基建（auth / 网关 / 匹配 / PG / Redis / 60Hz 服务端核心，PG 迁移已验收）封存为二期起点资产；一期 Transport 抽象保证客户端协议层可无缝切回中心服务器。二期形态（同 IP 大版本 or 新游戏）届时由用户定。
