# AsterNova 总蓝图（BLUEPRINT）

> 状态：**v1.0 定稿**（2026-08-30）。本文是 AsterNova 所有开发决策的最高锚点；任何实现与本文冲突时以本文为准，修改本文必须由用户（TimeCraker）拍板。
>
> 配套文档：[architecture.md](architecture.md)（技术定案）· [STYLE.md](STYLE.md)（美术风格圣经）

## 愿景

- **先做出高质量的游戏**，暂不考虑商业化；玩法方向已定案（2026-08-31，见「玩法」节），机制细节随开发由用户主导深化。
- **轻量高性能**：低配设备流畅，高配设备享受更高帧率与更精致画面（三档画质分级，运行时可切；**渲染帧率 120 起步上不封顶**，模拟 60Hz tick 与渲染帧率解耦）。
- **画面走二次元角色渲染**：对标崩铁 / 原神 / 绝区零 / 终末地 / 鸣潮的画风（toon ramp + SDF 面部阴影 + 描边 + 后处理），风格化路线，不做写实。
  - 预期管理：可复制的是**技术管线**；零授权 AI 资产管线的现实上限是"风格统一、干净讨喜的独立游戏二次元画风"，逼近上限靠 STYLE.md 约束 + 用户验收把关。
- **全栈零授权成本**，只用开源 / 免费工具；本机不跑 AI 推理。
- **分工**：用户只负责指挥、设计玩法、审核验收；代码、建模、测试、部署全部由 agent 完成。所有改动必须可验证（测试 / 构建 / 真实运行），渲染与资产先出验证件给用户过目再批量生产。

## 产品形态（2026-08-31 重大定案：单机优先 + 房主联机）

- **一期 = 单机为主的 3D 动作游戏**：游戏本体单机可玩；联机为**房主模式**——房主进程即权威端，**2~6 人 PvE 合作**开黑。防作弊按好友场景合理松弛。
- **玩法**：3D 自由视角动作（绝区零 / 鸣潮式「3D 世界跑着打架」）+ **Roguelite 单局**；**设计北极星指标**（North Star Metric：一切设计决策对着校准的唯一核心目标）= **爽感与上瘾性**——任何玩法设计先问爽不爽、上不上瘾（机制细节随开发由用户主导定稿）。
- **模拟核心**：GDScript 战斗核心跑在 Godot 进程内（60Hz 固定步长）；单机 = 本地直调，联机 = 房主权威 + 快照广播；**客户端分层预测**（位置/出手预测 + 关键结果房主独裁，细则见 architecture §2）。
- **联机连接策略（2026-08-31 修订：两套栈）**：**Steam 版 = Steam Networking 一条道**（GodotSteam，内部自含「直连优先 → 自动升 Valve 免费中继」，不叠手搓逻辑）；**非 Steam 版（Web demo / 官网直发版）= 手搓降级**：局域网发现 → IPv6 直连 → UPnP → UDP 打洞（ENet 落地后）→ 自建中继（后置）。**一期不自建任何中心服务**——Steam 版联机零自建成本；自建中继的「收费增值」记为二期商业位。
- **Go 后端基建（auth / 网关 / 匹配 / PG / Redis / 60Hz 服务端核心）封存为二期「大型联机游戏」起点资产**（见「二期规划」）。
- **三端优先级**：**Steam（Windows exe）首发**；Web = 试玩 demo 引流位；Android 后置（触屏动作适配成本届时评估）。
- **UI 分界（2026-08-31 复核定案：React 主方案）**：菜单 / 设置类 = **React**（Windows 走 WebView2 嵌入，系统组件；手柄用现成空间导航库；Steamworks 由 Godot 进程持有 + 桥接暴露给菜单）；游戏内 UI（HUD 等）= **Godot**。M3 spike 三验收（手柄操作 / 成就从菜单弹出 / 嵌入稳定性），不过才退 Godot 菜单。

### M1 渲染垂直切片（美术验证件）← **当前（与 M2 并行）**

一个二次元人形角色 + **现代日本晴空住宅街区（一户建 + 樱花坡道 + 坡顶鸟居）**场景（2026-09-04 用户定案：日漫清新日常气质，参考《秒速五厘米》《咒术回战》《天气之子》下午 14:30 晴空少云观感，CS2 级 Trim Sheet 工业管线）走完整条资产管线（原画 → 粗模 → Blender 打磨 → 二次元渲染四件套 → 三档画质），出真机截图 / 视频给用户验收。验证件按 3D 自由视角战斗场地的镜头构图出。

- 验收标准：**用户对画面水准说"过"**，才允许批量生产；不过则迭代管线或调 STYLE.md。
- **第一周目标（外部审查定案）：先打通 VRM → Godot 正确显示链路**——MToon 材质映射到自研 toon shader、blendshape 表情命名约定、SDF 面部阴影贴图按最终拓扑重烘焙、Blender bpy → KTX2 工具环节；链路通了再谈画质（M1 真风险在转换链，不在 shader）。

## 验收节奏

- **agent 日常闭环**：headless 测试（Go 回放 / GdUnit4）+ 截图自检，不事事上抛。
- **用户验收**：每个里程碑交付一键可跑的 demo build，用户只验里程碑件；用户时间优先花在玩法决策与美术验收。
- **性能红线**：tick 预算 16.6ms / GC 停顿 / RTT P95 一律以实测数据为准，不凭感觉换语言换组件；模拟核心热核保持独立模块，性能红线触发才可用 GDExtension（C++ 或 Rust，届时按生态选）重写该热点。

## 玩法（2026-09-04 核心机制定案）

- **设计北极星**：**极致的战斗爽感与上瘾性**（经典套路做到极致、精致与纯粹逻辑）。
- **极限身法与机动（Apex / 鬼泣式灵活爽感）**：
  - **贴地滑铲（Slide）**：疾跑（7m/s）中按 `C` 爆发至 12m/s，平地滑行 0.85s（~7m），下坡重力加速无限长滑；滑铲中按空格（滑铲跳）保留 90% 前冲动量；碰撞高度压至 0.85m；派生滑铲出刀与滑铲蓄力。
  - **极限立体机动（Vertical Mobility）**：一段跳高度 3.2m，二段跳升空 2.5m（总高 5.7m）；下落重力翻倍 1.8x 防飘浮；贴墙按跳触发蹬墙跳（朝外斜上方弹射 4.5m，上限 3 次）；空中按下蹲触发「星坠断空」垂直极速下砸冲击波。
  - **操作控制与双视角**：
    - **4.5米智能软锁定吸附（Soft-lock）**：出刀向准星前方 4.5m 目标微滑步吸附，彻底杜绝二次元 3D 挥刀砍空气痛点；
    - **按 V 键自由切换双视角**：第三人称越肩追尾（看全身背影、呆毛与流光刀术）与第一人称主观沉浸持刀（幽灵行者拔刀）一键平滑切换；
    - **速度动态运镜**：速度越快 FOV 从 75° 动态拉大至 88° 并压低贴地俯冲；
  - **核心打击感与反馈节奏**：
    - **平砍命中**：0.05s 微顿帧（Hitstop），四段连击行云流水；
    - **居合拔刀**：长按 RMB 纳刀架刀；0.4s 1阶(3m) / 0.9s 2阶(6m) / 1.5s 满阶次元穿透(10m)；架刀前 0.15s 受击触发「完美弹刀（Parry）」震飞破绽；命中触发 0.10s 强卡肉顿帧 + 平滑创伤震屏（Trauma Shake）。
- **近战剑士 Aster 三大平衡流派（数值克制不超标）**：
  - **【疾驰动量·破空瞬拔】**：高机动身法流。跑动、滑铲、蹬墙与极闪持续积攒动能层数；极闪瞬移至怪身后将动能转化为零前摇拔刀，刀光直线贯穿整排敌人并引发音爆。
  - **【分段蓄力·破绽重斩】**：重剑式节奏。长按分段蓄力（1~3 阶），架刀期间移速受限且会被打断（考验抓怪后摇破绽），仅在挥刀出手的瞬间拥有短暂抗打断；伤害扎实（2~3 倍平砍），消韧适中，不超模、不无脑站撸。
  - **【印记叠加·连击引爆】**：节奏连击流。平砍连招与特定身法为怪物叠加机制印记；收刀入鞘瞬间一次性连锁引爆全场印记。
- **局内构筑（Build）：4 主槽 + 1 趣味挂件槽（完全解耦自由混搭）**：
  - **4 大核心功能槽**：【拔刀槽】、【身法槽】、【战技槽】、【被动心法槽】完全独立解耦，玩家可自由杂交（例如：用疾驰流的滑铲极闪 + 蓄力流的 3 阶重斩）。
  - **1 个趣味挂件槽**：零 3D 建模负担的 2D 头顶贴图/搞怪音效挂件（极闪弹幕吐槽机、招财猫喵喵叫等）。
  - **即插即用**：背包随时 0 损耗更换模块；智能一键整理；冗余模块一键分解为金币。
- **战场生态与关卡循环**：
  - **敌人配置三合一**：
    - ① 割草近战杂兵：成群散布，检验滑铲横扫割草与动能积攒；
    - ② 远程炮手：定点发射法球，逼出蹬墙跳与滑铲突进；
    - ③ 韧性精英怪：平时横刀胸前正面格挡平砍（清脆弹刀音效与火花，防无脑连点刮痧）；蓄力重斩、战技或身法绕后可直接穿透破防；抬手蓄力攻击时武器/眼睛闪过微光露出绝对破绽，玩家直接出刀可打断或暴击反制。
  - **单局结构**：3~4 个递进街区（单局 15~20 分钟），暂定城市樱花校区/坡道街区雏形，关底决战结算。
  - **场景补给与彩蛋**：贩卖机战术补给；街机打地鼠/神社求签定位为轻量趣味彩蛋，主线完成后按需引入。
- **联机协作（2~6人房主 PvE）**：
  - 全员皆为主力输出，不强制战法牧分工。
  - 核心机制：① 倒地救援（队友按 F 键 2 秒扶起，全队皆倒才失败）；② 破韧全队集火（Boss 破韧跪地瘫痪时全队暴击/伤害大幅提升）。
- **经济与双轨养成**：
  - **局内**：经验升级逐步解锁 4 个槽位（Lv.1~Lv.9）；局内金币随时在背包面板升级模块星级或分解。
  - **局外**：双货币体系。【星尘】微调基础容错（生命上限、初始汽水，封顶提升 30% 绝不数值膨胀）；【虚空晶石】解锁新角色、高阶模块掉落池图鉴蓝图与外观。保证新手老手联机战力公平。
- 带宽：快照热路径用增量 + 量化编码（见 architecture §4「快照编码与带宽」），设计目标 ≈20KB/s/人，家庭宽带与 Steam 中继均无压力。

## 二期规划（占位）

- **大型联机游戏（中心服务器架构）**：现有 Go backend 基建（auth / 网关 / 匹配 / PG / Redis / 60Hz 服务端核心，PG 迁移已验收）封存为二期起点资产；一期 Transport 抽象保证客户端协议层可无缝切回中心服务器。二期形态（同 IP 大版本 or 新游戏）届时由用户定。
