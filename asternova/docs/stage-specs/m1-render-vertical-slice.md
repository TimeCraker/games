# Stage Spec：M1 渲染垂直切片（美术验证件）

> 状态：**待用户放行**（2026-08-30 起草）。上游锚点：[BLUEPRINT.md M1](../BLUEPRINT.md) · [architecture.md §1](../architecture.md) · [STYLE.md](../STYLE.md)（风格约束源）。
> 本阶段**纯美术与渲染**，不含任何玩法逻辑与网络代码。

## 目标（一句话）

用完整资产管线做出「一个二次元人形角色 + 黄昏樱花商店街」的可交互渲染切片，以真机三档画质截图/视频回答一个问题：**画面水准是否达到用户底线**——过，则管线定型、STYLE.md 定稿、允许批量生产；不过，则迭代管线或调风格，不进批量。

## 定案输入（已由用户拍板）

- 角色：二次元人形（对标五作画风）
- 场景：黄昏樱花商店街——日漫动画经典樱花场景气质（《路人女主》樱花斜坡、《秒速五厘米》樱花雨、《你的名字》黄昏光一脉的**观感**），不临摹具体画面
- 氛围四要素：樱花花瓣粒子 · 黄昏暖侧光 · 灯笼/招牌点灯 · 坡道纵深构图

## 范围内

### A. 资产管线全链路（首次实跑）

1. **角色**：
   - ChatGPT 生图：角色设定 + 正交三视图（prompt 引用 STYLE.md §1/§2 已定项，未定项按"参考五作画风"占位并在报告标注）
   - 粗模：VRoid（日式人形适配）或 Hugging Face 在线 image-to-3D，二选一实跑并记录成品质量对比
   - Blender 5 + bpy agent 打磨：减面 / UV / 法线烘焙 / 骨骼适配（Godot 骨骼命名）
   - 导出 GLB + KTX2 压缩贴图，Godot 导入预设
2. **场景**：坡道商店街模块化资产（店面 ×2-3 / 招牌灯笼 / 樱花树 / 路灯 / 电线杆）、天空盒（黄昏渐变 + 云）
3. **里程碑式小批交付**：角色粗模先出一次预览截图（不过管线后段），用户可中途看方向对不对，但不做正式验收

### B. 渲染（Godot 4.5）

载体：新建 `asternova/render-lab/`（独立 Godot 4.5.x 工程，纯渲染试验场，无网络代码；M2 的 client-godot-v2 后续直接搬用其渲染配置）。

1. 二次元渲染四件套：toon ramp 色阶 shader · SDF 面部阴影 · 描边（inverted hull 或后处理）· 后处理（bloom / 色彩分级 LUT / 暗角）
2. 樱花花瓣粒子系统（GPU 粒子，风场摆动）
3. 黄昏光照：主光角度/色温调教 + 灯笼/招牌 emissive 点光
4. 三档画质（低/中/高）运行时可切：低=关后处理+降分辨率，高=全特效——**每档出独立截图**
5. 相机：固定展示位 + 简易 orbit（验证材质在不同角度的表现）

### C. STYLE.md 回填

切片调教过程中把 §1-§5 的定稿值（配色 hex / toon 色阶数 / 描边宽度 / 光照参数 / 画质开关清单）回填 STYLE.md——**这一步完成 STYLE.md 才算从骨架变宪法**。

## 范围外（防扩散清单）

- 任何网络/玩法/战斗代码（M2 线）
- 大厅 UI / HUD、WebView（M3）
- 第二个角色、其他地图（验收通过后才是量产的事）
- 动画系统（角色绑定骨骼可 idle 站立即可，不做动作）
- 移动端真机（本阶段 Windows 编辑器 + exe 截图为准，真机验证归 M4）

## 验收标准（全部真机取证）

| # | 验收点 | 证据形式 |
|---|---|---|
| 1 | 角色完整走通管线（原画→粗模→打磨→GLB 进 Godot） | 各环节截图链 |
| 2 | 四件套齐全（关掉任何一个都能看出差别） | 特效开关前后对比图 |
| 3 | 三档画质各自截图 + 帧率标注（Windows 本机） | 截图 ×3 + fps |
| 4 | **用户过目说"过"** | 用户原话，记入 BLUEPRINT |
| 5 | STYLE.md §1-§5 全部定稿值回填 | git diff |

## 风险与预案

- **VRoid / image-to-3D 粗模拓扑不可用**（最可能翻车点）：预置备胎=用免费 T-pose 基础人模（如 VRM 公模）+ Blender 重塑面部与服装；切片目的就是暴露这类问题
- 花瓣粒子在高档帧率风险：预算超支则降粒子数并记录进 STYLE.md
- 黄昏光照 + toon ramp 冲突（暗部色阶糊掉）：调教记录全部写入 STYLE.md §3，作为后续所有场景的光照母版
