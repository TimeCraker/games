# Stage Spec：M1 渲染垂直切片（美术验证件）

> 状态：**待用户放行**（2026-08-30 起草）。上游锚点：[BLUEPRINT.md M1](../BLUEPRINT.md) · [architecture.md §1](../architecture.md) · [STYLE.md](../STYLE.md)（风格约束源）。
> 本阶段**纯美术与渲染**，不含任何玩法逻辑与网络代码。

## 目标（一句话）

用完整资产管线做出「一个二次元人形角色 + 现代日本晴空住宅街区（一户建 + 樱花坡道 + 坡顶鸟居）」的可交互渲染切片，以真机三档画质截图/视频回答一个问题：**画面水准是否达到用户底线**——过，则管线定型、STYLE.md 定稿、允许批量生产；不过，则迭代管线或调风格，不进批量。

## 定案输入（2026-09-04 用户 /grill-me 纠偏拍板）

- 角色：二次元人形 Aster（对标五作画风，倒 V 刘海，冷瓷肌色）
- 场景定位：**现代日本清新住宅街区（一户建 Suburb）**——日漫经典清新日常气质（《秒速五厘米》《咒术回战》《天气之子》《声之形》一脉的清爽现代观感，坚决告别古风木屋与红灯笼）
- 天气与光照：**下午 14:30 晴空少云**（清澈蔚蓝天空 + 明媚阳光 + 柔和青冷天光反弹），彻底杜绝黄昏暗部死黑，画面极致通透干净
- 氛围核心要素：二次元块面法线传递樱花树 · 飘落樱花花瓣粒子 · 柏油路面交通标线 · 现代水泥电线杆与拉线 · 自动贩卖机点缀

## 范围内

### A0. 链路先行（2026-09-05 全面重构定案）

打通 **Tripo3D 2.0 / Studio（Smart Mesh Quad 拓扑 + Auto-Rig 骨骼直出）→ Blender 比例与佩刀插槽装配 → Godot 4.7 二次元着色器与装配链路**（彻底废黜早期 VRoid / VRM 玩具链路与第三方 MMD 拆件拼接）：自研 Toon Shader 映射、SDF 面部平滑阴影贴图、内凹视差星空眼、Blender bpy → KTX2 贴图压缩——**链路通了才进画质调教**（M1 真风险在规范对齐，不在 shader）。

同周核查与底座升级（2026-09-06）：**渲染底座全面升级为 Forward+ (Vulkan Clustered)**，彻底根除 compatibility 下 2.88x 光照畸变与无 SSAO/SSR/探针硬伤；色彩科学确立为 **AgX（模式 4）**，描边采用 Inverted Hull，后处理采用标准 `endfield_studio_environment.tres`。实际可用清单记入 STYLE.md §3。

### A. 资产管线全链路（实跑复盘与工业级演进）

1. **角色管线踩坑与工业级重构（2026-09-05 终审定案）**：
   - **早期粗模教训**：初版 VRoid / 简易公模存在颅顶平塌、下巴圆钝、面部恐怖谷的问题；拆件拼装导致布线破损与侵权隐患。现已彻底确立 **100% 原生 AI 生产路线**。
   - **工业级标杆重构（对标《终末地》《鸣潮》实测）**：角色全套总预算确立为 **60,000 ~ 85,000 三角面（PC 旗舰档 120+ FPS）**，发型预算提升至 **15,000 ~ 22,000 面**（保证倒 V 刘海、胸前与背后多层立体流转与飘逸物理骨骼 SpringBone），面部 **8,000 ~ 12,000 面**，常服与百褶裙 **35,000 ~ 45,000 面**；LOD1 档严控在 **25,000 ~ 35,000 面**。
   - **几何与剪影雕刻**：刘海中央雕刻出 Aster 标志性的**倒 V 型空气刘海中缝**，自然展露额头与鼻梁轮廓；两侧 face-framing 细长发束顺下颚垂落；彻底切除外翻 900+ 破面翅膀尖刺。
   - **贴图洗净与底色校准**：彻底消除旧测试在 `aster_body_texture.png` 误烘焙的 50 万暗红颈部像素，修复右眼眶黑印，统一采用白皙冷调瓷肌色 `#FDF1EA`。
   - **视口布光避坑规范**：规避太阳光欧拉角指向脑后导致的前脸死灰判定（NdotL < 0），确立正面主光 + 辅助冷光 + 顶侧轮廓光的标准审查光照。
2. **必配饰件装配与验收加固**：
   - 严禁半成品无饰件验收：Aster 必须完整装配①左鬓双层白花+缎带、②领口维多利亚小圆领、③胸前浅蓝双层领结+珍珠胸针、④后腰蝴蝶结。
   - 验收证据链：在 Godot 4.7.2 与 Blender 5.2.1 中以 2D 原画 `turnaround-final.png` 同款透视（中景半身 1:1 窗位）同框对比，视觉相似度 ≥ 90% 方可放行。
3. **场景建造技术（参考 31 张参考图美学与动线，单体逐个击破）**：
   * **【高精优先，LOD后置】策略**：首发保证单体结构饱满与二次元 PBR 质感；31 张图作为地图规划与美学参考锚点，绝非死板教条清单。追求大轮廓舒服、生活烟火气与干净通透，避免微观过度堆料导致开发拖沓。
   * **Tier 1 地面基建**：柏油路面、人行道、路沿石、盲道砖，走 **2K Trim Sheet + 平铺 PBR**（保证无缝大面积拼接、无接缝走样、极低显存）；
   * **Tier 2 核心单体建筑（生成不设上限，Tripo 最高档；LOD 参考 1.5w~3.5w 面）**：折角便利店、一户建住宅等，确立**「AI 生成底模 + 自动化几何手术修补（Surgery & Modular Enhancement）」**工业管线：参考图 / 45° 轴测图 ➔ Tripo3D 生成外观底模 ➔ 自动化 Blender 手术（切除破碎假玻璃与扁平 2D 贴纸，嵌装铝合金正交窗框、高透双层 PBR 钢化玻璃与真实 3D 室内货架陈列）➔ 标定 2m/4m 网格吸附与规整导出，彻底消灭 AI 塑料感与穿模，保留 85% 原生体量与外墙 PBR；
   * **Tier 3 街景高频小道具（生成不设上限，Tripo 最高档；LOD 参考 3k~1w 面）**：双联自动贩卖机、空调外机架、日式分类垃圾箱、水泥电线杆拉线组、复古踏板摩托车，走 Tripo3D 原生单体生成 ➔ 几何手术切除非流形飞刃碎片并规整装配 ➔ 作为独立 Prefab 在引擎自由摆放；一个个逐个建模打磨；
   * **四区立体纵深沙盒动线**：
     - ① **北端高台边缘**：微型朱红鸟居 + 小木神龛 + 苍劲古樱花树（作为全图由下往上仰望的天空视觉地标 Landmark）；
     - ② **中央主干道**：40米长、6.5米宽的双向柏油坡道（15度下倾），专供极速滑铲下坡无限加速与落樱风场；
     - ③ **西侧一户建小巷与车库**：住宅1(带4.5m二段跳阳台) + 住宅2(开放式车库室内) + 3.5m民居夹墙(专供3次折返蹬墙跳)；
     - ④ **南端街角广场**：红蓝现代高精贩卖机、凸面反光镜与护栏，摆放受击木桩与红光反击傀儡进行 4 段普攻吸附、0.15s 弹刀与极闪实战。
   * **二次元樱花树（Normal Transfer）**：优美树干 + 蓬松圆润树冠块面（Leaf Clusters），球形法线传递消除碎黑面，面数严控在 2,500 面以内；
4. **三阶段渐进开发与截图自检流水线**：
   - Phase 1（建筑与地形底座）：1张 2K Trim 图集 + 3栋一户建与坡顶小鸟居，立刻无头渲染 3 视角截图自检清晰度与比例；
   - Phase 2（樱花树与街道道具）：制作块面法线樱花树、电线杆拉线、自动贩卖机与反光镜，渲染街区生活感全景截图；
   - Phase 3（沙盒组装与实机对比）：在 Godot 中配上晴空下午阳光与隐形平滑碰撞体，摆放打怪靶子，输出最终实机画面对比验收。
5. **专属佩刀「星霜月华」3D 低模与拔刀分件装配定稿（2026-09-04 回填）**：
   - **设计基准**：严格锚定 `art/characters/aster/weapon-turnaround-final.png` 官方 2D 正交全分件设定图。
   - **性能与拓扑**：总面数 **899 三角面**（刀身组 503 面，刀鞘组 396 面），彻底杜绝繁复微观雕花的性能浪费，为 120 FPS 留足预算。
   - **分件装配**：刀身组（`Blade_Mesh`）与刀鞘组（`Scabbard_Mesh`）独立拆分，局部原点统一锁定在【刀鞘口】`(0, 0, 0)`，实现出入鞘零偏置线性移动。
   - **材质图集**：单张 `2048x2048` BaseColor Atlas（象牙白微珠光鞘、深蓝柄卷、浅蓝蝴蝶结系绪、冷天蓝刃纹、香槟金四芒星护手）。
   - **交付产物**：工程源文件 `aster_katana.blend`、游戏通用资产 `aster_katana.glb`、贴图 `tex_katana_basecolor.png`、高精对比看板 `katana_preview.png`、以及自包含 3D Web 检视器 `aster_katana_3d_viewer.html`。
   - **工业化实践 SOP 详见**：[docs/pipeline/weapon-modeling-pipeline.md](../pipeline/weapon-modeling-pipeline.md)。

## M1 场景切片评审结论与 31 张参考图差距备忘（2026-09-07 评审定案）

> **评审总体判定**：**骨架与大感觉已跨过质量底线（综合评分 75 ~ 80 分，准予作为 M1 场景阶段性基线放行）**。
>
> ⚠️ **2026-09-10 制作人复审判定**：建筑与角色观感「丑、不稳定」，**原「阶段性基线放行」作废**；M1 验收回到 BLUEPRINT 原标准——**制作人亲口说「过」才允许批量生产**。下方差距清单（道具密度 / 立面微表面 / 角色动态）继续有效，其中第 3 项（角色）升级为参考图驱动闭环专项攻坚（见 modular SOP §2.6）。
> 场景已为角色动作与战斗手感提供了真实通透的光影环境（Forward+ Clustered + AgX 模式 4）、地面碰撞支撑与冷暖视效张力。在工业化开发中，避免因微观细节停滞主流程，将以下 3 项客观差距正式记入技术文档储备池，待后续版本（M2 或专门美术精修排期）有充裕时间再专项打磨优化。

### 1. 达标项（PASS）
- **影调与天光氛围（对齐《终末地》90 分）**：ProceduralSky 清冷双半球天光、微蓝机能灰阶、AgX 模式 4 高光通透不炸、暗部不发黑，彻底摒弃《绝区零》过度泛黄高饱和与脏噪点。
- **地面 PBR 物理质感（85 分）**：真实骨料沥青微法线、平直干净的斑马线与规范防滑黄色盲道，消灭了纯平色块与自发光蓝塑料感。
- **核心建筑进深与冷暖对冲（80 分）**：Tier 2 折角便利店实打实置入 3D 实体货架陈列、彩色商品盒、天花板暖白 LED 与迎宾地灯，透过双层高透钢化玻璃形成室内暖光（3000K）与室外清冷天光（6500K）的视觉张力。

### 2. 存在差距的 3 个短板（后期精修待办清单）
1. **街道生活道具密度与烟火气（Street Clutter & Props Density，当前约 60 分）**：
   - **参考图基准**：31 张参考图街角密布外挂空调室外机群、架空变压器与垂落电缆、日式分类垃圾桶、侧挂发光灯箱、道路施工锥桶与水马。
   - **当前差距**：当前沙盒主要由便利店、双联贩卖机、邮筒与两株樱花树构成，整体偏整洁园区感，缺少“有人居住的市井真实生活痕迹”。
   - **优化计划**：在 M2/后置道具专项中，按 Tier 3 Prefab 规范批量建模空调室外机、电缆走线组与日式分类垃圾桶，提升街角道具密度。
2. **建筑外立面风化与微表面结构（Decals & Facade Seams，当前约 65 分）**：
   - **参考图基准**：参考图的大块建筑外墙具有清晰的预制混凝土分缝线、金属导水板、墙角轻微水渍与警示条纹贴花。
   - **当前差距**：右侧与后侧护栏/墙体大面积呈现为均质深灰混凝土块，体量偏重，缺少二阶微表面细节。
   - **优化计划**：引入 Decal 贴花系统（混凝土接缝、水渍污垢、防撞警示条），破除大块均质墙面的单调感。
3. **角色动态与在场感（Actor Dynamic Presence）**：
   - **参考图基准**：参考图中角色身姿飒爽（压重心疾跑、拔刀待发、衣摆随风飘逸）。
   - **当前差距**：当前沙盒中 Aster 仍以静态展位呈现。
   - **前置依赖**：需等待外部角色动作 Agent 完成 43 骨蒙皮手术与 Mixamo 动捕动作库（MeleeLib 121 + ShooterLib 180）重定向与动作树融合后方可完全展现。

## 风险与预案

- **VRoid / image-to-3D 粗模拓扑不可用**（最可能翻车点）：预置备胎=用免费 T-pose 基础人模（如 VRM 公模）+ Blender 重塑面部与服装；切片目的就是暴露这类问题
- 花瓣粒子在高档帧率风险：预算超支则降粒子数并记录进 STYLE.md
- 黄昏光照 + toon ramp 冲突（暗部色阶糊掉）：调教记录全部写入 STYLE.md §3，作为后续所有场景的光照母版
