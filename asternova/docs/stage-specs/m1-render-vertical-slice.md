# Stage Spec：M1 渲染垂直切片（美术验证件）

> 状态：**待用户放行**（2026-08-30 起草）。上游锚点：[BLUEPRINT.md M1](../BLUEPRINT.md) · [architecture.md §1](../architecture.md) · [STYLE.md](../STYLE.md)（风格约束源）。
> 本阶段**纯美术与渲染**，不含任何玩法逻辑与网络代码。

## 目标（一句话）

用完整资产管线做出「一个二次元人形角色 + 黄昏樱花商店街」的可交互渲染切片，以真机三档画质截图/视频回答一个问题：**画面水准是否达到用户底线**——过，则管线定型、STYLE.md 定稿、允许批量生产；不过，则迭代管线或调风格，不进批量。

## 定案输入（2026-09-04 用户 /grill-me 纠偏拍板）

- 角色：二次元人形 Aster（对标五作画风，倒 V 刘海，冷瓷肌色）
- 场景定位：**现代日本清新住宅街区（一户建 Suburb）**——日漫经典清新日常气质（《秒速五厘米》《咒术回战》《天气之子》《声之形》一脉的清爽现代观感，坚决告别古风木屋与红灯笼）
- 天气与光照：**下午 14:30 晴空少云**（清澈蔚蓝天空 + 明媚阳光 + 柔和青冷天光反弹），彻底杜绝黄昏暗部死黑，画面极致通透干净
- 氛围核心要素：二次元块面法线传递樱花树 · 飘落樱花花瓣粒子 · 柏油路面交通标线 · 现代水泥电线杆与拉线 · 自动贩卖机点缀

## 范围内

### A0. 链路先行（第一周目标，2026-08-31 外部审查定案）

先打通 **VRM → Godot 正确显示**：MToon 材质映射到自研 toon shader、blendshape 表情命名约定、SDF 面部阴影贴图按最终拓扑重烘焙、Blender bpy → KTX2 工具环节——**链路通了才进画质调教**（M1 真风险在转换链，不在 shader）。

同周核查：**CompositorEffect 在 Compatibility 渲染器不可用**（GL 路线无 compute）→ 描边锁定 inverted hull、后处理收缩到内置 Environment（glow / tonemap / LUT），实际可用清单记入 STYLE.md §3。

### A. 资产管线全链路（实跑复盘与工业级演进）

1. **角色管线踩坑与工业级重构（2026-09-04 回填）**：
   - **早期粗模教训**：初版 VRoid / 简易公模存在颅顶平塌、下巴圆钝的问题；而在发型打磨时盲目自捏微细发丝或密集透明面片，直接引发多边形爆炸与远景走样，严重违背 120 FPS 性能红线（Overdraw 灾难）。
   - **工业级标杆重构**：果断叫停在劣质基模上的低效修补，深度调研《原神》《鸣潮》工业管线，切换至工业级二次元块面基模（`render-lab/models/aster/aster_head_base_v2.blend`），发型面数严控在 3,000~5,000 面。
   - **几何与剪影雕刻**：刘海中央雕刻出 Aster 标志性的**倒 V 型空气刘海中缝**，自然展露额头与鼻梁轮廓；两侧 face-framing 细长发束顺下颚垂落；彻底切除外翻 900+ 破面翅膀尖刺。
   - **贴图洗净与底色校准**：彻底消除旧测试在 `aster_body_texture.png` 误烘焙的 50 万暗红颈部像素，修复右眼眶黑印，统一采用白皙冷调瓷肌色 `#FDF1EA`。
   - **视口布光避坑规范**：规避太阳光欧拉角指向脑后导致的前脸死灰判定（NdotL < 0），确立正面主光 + 辅助冷光 + 顶侧轮廓光的标准审查光照。
2. **必配饰件装配与验收加固**：
   - 严禁半成品无饰件验收：Aster 必须完整装配①左鬓双层白花+缎带、②领口维多利亚小圆领、③胸前浅蓝双层领结+珍珠胸针、④后腰蝴蝶结。
   - 验收证据链：在 Godot 4.7.2 与 Blender 5.2.1 中以 2D 原画 `turnaround-final.png` 同款透视（中景半身 1:1 窗位）同框对比，视觉相似度 ≥ 90% 方可放行。
3. **场景建造技术（全面对标 CS2 / Source 2 工业标准）**：
   - **Trim Sheet + Hotspot UV**：整套现代住宅建筑共用一张 2K 现代外墙图集（米白防水砖、浅灰瓷砖、铝合金窗框、黑色阳台栏杆、踢脚线），极低显存、极限像素清晰度；
   - **模块化砌块（Modular Kit）**：标准 2m/4m 网格对齐的标准墙段、外转角、阳台、车库门与屋顶；
   - **二次元樱花树（Normal Transfer）**：优美树干 + 蓬松圆润树冠块面（Leaf Clusters），球形法线传递消除碎黑面，面数严控在 2,500 面以内；
   - **现代街景道具（Detail Props）**：水泥电线杆(带变压器与拉线)、路口凸面反光镜、红蓝自动贩卖机、不锈钢人行道护栏、柏油马路标线。
4. **里程碑式小批交付**：角色粗模先出一次预览截图（不过管线后段），用户可中途看方向对不对，但不做正式验收

### B. 渲染（Godot 4.7.2 Stable）

载体：新建 `asternova/render-lab/`（独立 Godot 4.7.2 工程，纯渲染试验场，无网络代码；M2 的 client-godot-v2 后续直接搬用其渲染配置）。

1. 二次元渲染四件套：toon ramp 色阶 shader · SDF 面部阴影 · 描边（**inverted hull 定案**）· 后处理（**内置 Environment：bloom / 色彩分级 / 暗角**）
2. 樱花花瓣粒子系统（GPU 粒子，微风摆动扰动场）
3. 晴空下午光照：主阳光角度与暖白纯度调教 + 蔚蓝天光冷色间接漫反射 + 贩卖机自发光
4. 三档画质（低/中/高）运行时可切：低=关后处理+降阴影，高=全特效——**每档出独立截图与帧率**
5. 相机：固定展示位 + 简易 orbit（验证材质在不同角度的表现）

## 风险与预案

- **VRoid / image-to-3D 粗模拓扑不可用**（最可能翻车点）：预置备胎=用免费 T-pose 基础人模（如 VRM 公模）+ Blender 重塑面部与服装；切片目的就是暴露这类问题
- 花瓣粒子在高档帧率风险：预算超支则降粒子数并记录进 STYLE.md
- 黄昏光照 + toon ramp 冲突（暗部色阶糊掉）：调教记录全部写入 STYLE.md §3，作为后续所有场景的光照母版
