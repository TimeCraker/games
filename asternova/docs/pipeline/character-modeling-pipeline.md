# AsterNova 3D 二次元高精角色工业化制作管线指南（Character Modeling Pipeline SOP）

> **文档定位**：本项目所有 3D 二次元高精角色（主角 Aster、未来队友与人形 Boss）的**唯一技术实践与标准化生产指南**。  
> **设计标杆**：严格对标**《鸣潮》（Wuthering Waves）与米哈游次世代（枫丹/纳塔级）** 8.5 头身成熟仙气体态与美型面部拓扑，**彻底杜绝早期原神与 VRoid 式的大头娃娃与廉价玩具感**。  
> **生效时间**：2026-09-05 起生效。后续任何角色的 3D 生产必须严格恪守本 SOP。

## 1. 核心设计哲学与历史教训复盘

### 1.1 历史教训红线（彻底禁绝的四大歧途）
在之前的原型迭代中，曾因技术选型走偏出现灾难性残次模型，所有进入项目的 Agent **必须绝对遵守以下禁令**：
1. ❌ **严禁使用 Python PIL 脚本用数学代码画贴图**：二次元眼睛、睫毛与面部纹理是毫厘级的手绘艺术品，代码画圆画出的“死鱼眼”和“色块”是恐怖谷的直接元凶。
2. ❌ **严禁使用数学公式或坐标区间暴力拉伸顶点捏脸**：面部拓扑必须遵循严格的面部五官环形布线（Edge Loops），代码粗暴缩放顶点会直接拉毁面部曲率，产生蛇精脸与法线阴影黑斑。
3. ❌ **严禁使用低幼粗糙底模（如 VRoid 玩具素体）硬缝**：素体的头身比、天鹅颈、骨盆与腿型决定了角色的上限，必须使用 8.5 头身成熟工业级美型基模。
4. ❌ **严禁虚假量化自嗨（Metric Gaming）**：严禁在脚本中硬编码“相似度 93.8%”等自欺欺人指标擅自宣布通过。所有阶段验收必须以**制作人（用户）肉眼审查真实 2K 渲染图**为唯一基准！

### 1.2 鸣潮级三大核心法则
1. **8.5 头身修长体态**：九头身比例、修长笔直长腿、微溜优雅天鹅颈、克制纤细的骨盆与腰线，兼具少女轻盈与战斗飒爽。
2. **SDF 极净非真实感面部渲染（NPR Face Shading）**：面部光影彻底与真实物理粗糙阴影解耦，采用日漫工业级平滑面部光照贴图，任何角度光照下均不产生眼窝/鼻下脏阴影。
3. **大形归纳发簇与分层轻纱立体结构**：拒绝细碎面片或实心硬块，发簇大块归纳+法线球化，裙摆多层物理网格分离+双通道深度预写（Depth Prepass），还原仙气通透感。

## 3. 面部与眼神 NPR 核心技术管线

### 3.1 SDF 阈值面部阴影（Signed Distance Field Shadow）
- 严禁让面部顶点接收实时的 Lambert / PBR 漫反射直接物理光照！
- **原理**：将头部水平旋转 360° 下的面部平滑阴影切线烘焙进 Face 贴图的特殊通道（或独立一张 512x512 SDF 纹理）；
- **着色器逻辑**：
  $$\text{ShadowThreshold} = \frac{\text{LightDir} \cdot \text{HeadRight}}{2} + 0.5$$
  通过采样 SDF 纹理并与光照方向夹角进行平滑阶梯比对（`smoothstep`），实现手绘日漫动画级别的极致干净阴影。

### 3.2 视差内凹星空眼（Parallax Recessed Iris）
- **网格解耦**：眼眶前为透光微凸角膜，虹膜与瞳孔向眼眶内部物理微凹（2~3mm）；
- **视差微移**：视线根据观察者视角自动产生“目光注视”效果（视线跟随）；
- **高光图层独立**：星空眼底色、星芒点缀与主高光采用自发光/独立通道，不受弱光场景污染，永远闪烁灵动。

### 3.3 睫毛与眉毛透发渲染（Show In Front）
- 眉毛与睫毛网格使用特殊的渲染次序通道（Render Queue / Stencil Buffer）；
- 在被前刘海遮挡时，保持 35%~50% 的微透明度淡出穿透，确保角色在任何角度下表情神态清晰可辨。

## 5. 四阶段严格里程碑卡点制（Four-Milestone Gatekeeping）

每一个阶段都必须产出指定视角的 2K 纯净无损渲染图，**由制作人（用户）在对话中亲自确认通过后，才准推进到下一个阶段**。

- **交付资产**：`art/models/aster_milestone1_head_body.blend` / `.glb`
- **必须达标项**：
  - 8.5 头身鸣潮级修长比例，修长双腿，天鹅颈，绝无“大头娃娃”幼态感；
  - 面部拓扑完美圆润，无任何奇怪棱角或凹坑；
  - 凹面星空眼 + SDF 干净面部阴影着色生效。
