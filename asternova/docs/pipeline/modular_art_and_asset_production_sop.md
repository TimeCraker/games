# AsterNova 场景与角色工业化生产管线指南（Modular Art & Asset SOP）

> **生效日期**：2026-09-05 起正式生效。  
> **核心宗旨**：彻底废黜“Agent 代码硬搓方块几何体”的歧途，确立**「2D 概念生图 ➔ 3D AI 单体原生生成 ➔ Agent 拓扑组装与引擎装配」**的工业化分工体系；视觉与性能全面对标**《明日方舟：终末地》（Arknights: Endfield）**的高级机能美学与极致性能克制。

---

## 1. 痛点复盘与核心认知红线

在之前的技术试错中，暴露了严重的“闭门造车”短板，所有进场 Agent **必须绝对恪守以下三条红线**：
1. ❌ **严禁 Agent 用代码手搓场景建筑（严禁火柴盒式白模）**：
   Agent 靠简单的 Cube/Cylinder 和平铺贴图拼出来的房屋，本质是千禧年 PS2 水平的单调积木，毫无设计感与结构剪影，再强的后处理光影也无法弥补几何体本身的拙劣。
2. ❌ **严禁试图用 AI 3D 一键生成整张大地图**：
   AI 3D 工具（如 Tripo3D）目前擅长且仅擅长“单体物体（Props/Buildings）”，一旦整街生成就会塌陷成无法进入、无法行走的实心畸形泥团。
3. ❌ **严禁盲目堆砌几百万面数自嗨**：
   好的美术绝不是无脑堆多边形。必须学习《明日方舟：终末地》的工业机能设计哲学——**低面数、高辨识度剪影、斜切角结构、精致倒角与精细法线贴花**，在极低性能消耗下呈现出顶级商业质感。

## 2. 三位一体工业化资产生产链条（Triad Pipeline）

```
┌───────────────────────────┐      ┌───────────────────────────┐      ┌───────────────────────────┐
│   1. 概念与立面原画设计    │ ──>  │    2. 单体高精 3D 神经生成   │ ──>  │  3. Agent 拓扑组装与实装  │
│   (ChatGPT / Midjourney)  │      │        (Tripo3D 2.0)      │      │     (Blender & Godot)     │
└───────────────────────────┘      └───────────────────────────┘      └───────────────────────────┘
   • 输出正/侧/背严谨三视图            • 输入 2D 原画生成单体 .glb          • 尺寸标定与对齐地面
   • 建筑单体立面与转角设计            • 产出原生高精雕刻网格与贴图         • 智能减面与四边面 Quad 拓扑
   • 街景模块化构件（遮阳棚/灯箱）       • 保留纯粹曲面细节与 PBR 法线        • 分件拆解（手臂/衣服/发束）
   • 终末地级工业机能质感参考                                              • 骨骼绑定、碰撞体、关卡排版
```

### 2.1 环节一：2D 概念设计（负责审美与结构定义）
* 使用 ChatGPT / Midjourney 输出带有明确结构设计的单体原画：
  * **角色**：正/侧/背三视图（如 Aster 终版三视图）；
  * **建筑单体**：两层日式沿街商铺立面、折角咖啡厅、斜顶便利店；
  * **街景小构件**：独立自动贩卖机、关东煮流动摊位、日式邮筒、街头长椅、绿植花箱。

### 2.2 环节二：Tripo3D 3D 原生生成（负责曲面与贴图资产化）
* 将单体原画输入 Tripo3D，利用其神经扩散模型直接导出高精单体 `.glb` 文件；
* 每一件资产都是独立的、结构饱满的完整模块（而非连在一起的废土）。

### 2.3 环节三：Agent 的核心职责（负责工程落地与系统装配）
Agent **绝不去当“蹩脚的原画师与雕刻师”**，Agent 的核心精力 100% 投入到工业级工程整合：
1. **尺寸标定与地面吸附**：统一度量衡（1 单位 = 1 米），确保道路宽度、门框高度、角色身高绝对标准；
2. **轻量化重拓扑（Endfield 风格）**：
   * 将 Tripo 生成的高模通过自动化脚本进行四边面规整与适度减面（建筑物单体控制在 2,000~5,000 面，道具 300~1,500 面）；
   * 确保 PC/移动端 120 FPS 满帧丝滑运行；
3. **角色分件解耦与骨骼装配**：
   * 拆分可动组件（躯干素体、头部面部、挥剑手臂、飘动裙摆、后部长发）；
   * 绑定标准 Humanoid 人形骨骼与次级弹簧物理骨（SpringBone）；
   * 配置武器握持点与刀鞘插槽；
4. **关卡组装与物理碰撞（Level Dressing & Collisions）**：
   * 将生成的建筑模块与道具在 Godot 场景中进行模块化编排（拼装街道、便利店外挂遮阳棚、转角立式招牌）；
   * 配置高精度 `CollisionShape3D`，守护滑铲坡道、蹬墙跳胡同与战斗擂台。

## 3. 场景工业化资产四级分级规范（Tier 1 ~ Tier 4 Taxonomy）

为彻底解决“Trim Sheet 模块化工艺”与“Tripo 3D 自由生成”的哲学冲突，本项目确立**四级场景资产制造与装配体系**：

| 层级 | 适用对象 | 制造工艺与数据源 | 贴图与材质策略 | 核心目标 |
| :--- | :--- | :--- | :--- | :--- |
| **Tier 1: 地面基础设施** | 柏油马路、坡道、混凝土路沿石、人行道砖、盲道条、斑马线 | **CS2 级 Trim Sheet + 平铺 PBR**<br>（2m/4m 网格吸附，程序化或高精扫描纹理） | 共享 1~2 张 2K PBR 图集（无缝平铺、微湿粗糙度对比） | 保证大面积地面无缝拼接、无接缝走样、零破绽、极低显存 |
| **Tier 2: 核心特色建筑** | 折角便利店、斜屋檐拉面馆、终末地机能公寓立面 | **GPT 立面原画 ➔ Tripo3D 生成 ➔ Blender 网格规整**<br>（尺寸严格标定为 2m/4m 整数倍，智能 Quad 减面至 2k~5k 面） | 建筑外墙 PBR 图集 + 45° 倒角 + 挑檐走廊结构 | 赋予建筑强烈的工业机能剪影与进深层次，拒绝平直积木白模 |
| **Tier 3: 街景高频小道具** | 自动贩卖机、空调外机架、日式垃圾箱、配电柜、雨棚、公交亭 | **Tripo3D 原生单体直出 ➔ Blender 批量规整**<br>（单件面数控制在 300~1,500 面） | 道具独立图集或通用道具图集（发光灯箱 Emissive、金属粗糙度） | 极大丰富街头烟火气与近景细节，作为独立 Prefab 自由摆放 |
| **Tier 4: 远景天际线** | 远景大厦剪影、层叠住宅群体块、远方山体/铁塔 | **低模体块剪影 + 视差贴花**<br>（单个建筑 50~200 面） | 远景雾化着色器 + 简单发光贴图 | 配合 Godot 4.7 体积雾（Volumetric Fog）营造深邃空间进深 |

## 4. 《明日方舟：终末地》级美术落地规范

1. **几何形体（Silhouette & Bevels）**：
   * 严禁出现直上直下的平直方块墙；
   * 建筑转角采用 45° 切角（Chamfer）、外挂结构柱、一层向外突出 0.8~1.5m 形成屋檐走廊；
   * 二层设计外挂钢结构维修连廊与空调挂机平台。
2. **材质表达（PBR & Decals）**：
   * 采用“底色克制 + 局部高饱和警示/霓虹点缀”的工业机能调色；
   * 大面积应用贴花（Decals）：斑马线、磨损警示黄黑斑马条、墙面导视路牌、排水口污渍；
   * 地面带有微湿粗糙度对比，反射室内溢出的暖黄色灯光。
3. **空间层次（Layering）**：
   * **近景（0~15m）**：高频细节（便利店玻璃橱窗内景、自动贩卖机按键与商品、绿植、分类垃圾桶）；
   * **中景（15~40m）**：结构剪影（二层露台、招牌灯箱、电线杆架空线路）；
   * **远景（40m+）**：大气透视（体积雾弱化细节，呈现层叠剪影）。
