# AsterNova 场景与角色工业化生产管线指南（Modular Art & Asset SOP）

> **生效日期**：2026-09-05 起正式生效。  
> **核心宗旨**：彻底废黜“Agent 代码硬搓方块几何体”的歧途，确立**「2D 概念生图 ➔ 3D AI 单体原生生成 ➔ Agent 拓扑组装与引擎装配」**的工业化分工体系；视觉与性能全面对标**《明日方舟：终末地》（Arknights: Endfield）**的高级机能美学与极致性能克制。

---

## 1. 痛点复盘与核心认知红线

在之前的技术试错中，暴露了严重的“闭门造车”短板，所有进场 Agent **必须绝对恪守以下三条红线**：
1. ❌ **严禁 Agent 用代码手搓场景建筑（严禁火柴盒式白模）**：
   Agent 靠简单的 Cube/Cylinder 和平铺贴图拼出来的房屋，本质是千禧年 PS2 水平的单调积木，毫无设计感与结构剪影，再强的后处理光影也无法弥补几何体本身的拙劣。
2. ❌ **严禁试图用 AI 3D 一键生成整张大地图**：
   AI 3D 工具（如 Tripo3D）目前擅长且仅擅长“单体物体（Props/Buildings）”，一旦整街生成就会塌陷成无法进入、无法行走的实心畸形泥团。
3. ❌ **严禁脱离工业现实的面数自嗨（厘清「场景克制」vs「角色堆料」的双轨标准）**：
   * **行业实测调研数据（2024~2026 次世代二游标杆）**：
     * **《明日方舟：终末地》**：PC/主机端角色实测高达 **80,000 ~ 100,000 三角面**（官方为 Unity 深度重构以承载普通游戏 1.5 倍面数）；移动端约为 40,000 ~ 50,000 面。所谓的“机能低面数”是针对**场景建筑**（中模大倒角 + 平直硬表面 + Trim Sheet + 法线贴花，单体建筑仅需 3k~8k 面），而**角色本身是高规格精模**！
     * **《鸣潮》**：PC 端角色通常在 **90,000 ~ 120,000 三角面**，极致追求长发丝滑分层、机甲细节与多重骨骼形变；
     * **《绝区零》**：角色常态 **35,000 ~ 60,000 三角面**，重点服务于全身全动画（Full Animation）的高频形变与夸张挤压拉伸；
     * **《原神》**：早期移动端妥协产物，常态仅 15,000 ~ 25,000 面（现代动作二游已全面超越此标准）。
   * **AsterNova 权威双轨预算基准（定稿）**：
     * **场景单体（克制极简）**：单体建筑严控在 **3,000 ~ 8,000 三角面**，街景道具 **500 ~ 2,500 三角面**，靠 45° 倒角与 PBR 材质出质感；
     * **角色 Aster（次世代高精）**：PC 旗舰档（120+ FPS）全套总预算确立为 **60,000 ~ 85,000 三角面**（长发 15k~22k、高精面部 8k~12k、服饰与配饰 35k~45k、佩刀 1k~1.5k），彻底告别塑料片廉价低模；LOD1 档自动规整至 **25,000 ~ 35,000 面**。

## 2. 工业化资产生产流水线（Modular Triad Pipeline）

```
┌───────────────────────────┐      ┌───────────────────────────┐      ┌───────────────────────────┐
│   1. 资产规划与 2D 概念设计 │ ──>  │    2. 单体高精 3D 神经生成   │ ──>  │  3. Agent 拓扑组装与实装  │
│   (按 Kit 规划 / GPT生图)  │      │        (Tripo3D 2.0)      │      │     (Blender & Godot)     │
└───────────────────────────┘      └───────────────────────────┘      └───────────────────────────┘
   • 严禁零散出模，按 Kit 套件规划       • 输入纯净概念图生成单体 .glb       • 尺寸标定（2m/4m 格网吸附）
   • 角色：严格正/侧/背三视图            • 产出原生高精雕刻网格与贴图         • 智能 Quad 拓扑与减面
   • 建筑/道具：45° 单张高清轴测图        • 杜绝拼凑畸形，保曲面饱满           • 碰撞体（CollisionShape3D）装配
   • 锚定 map_style 官方参考图库                                         • 街区 Prefab 乐高式组装
```

### 2.1 环节零：套件规划机制（Kit-based Planning，杜绝单件孤岛）
* 严禁无规划地单件零散制作，必须由制作人与主脑先行商讨敲定**「功能套件清单（Asset Kit List）」**，批量推进：
  * **Kit A（街角商铺套件）**：折角便利店主体 + 外挂遮阳棚 + 侧立式发光灯箱招牌；
  * **Kit B（街景高频设施套件）**：双联自动贩卖机 + 分类垃圾桶 + 水泥电线杆拉线组 + 空调挂机组；
  * **Kit C（路面动线套件）**：沥青下坡道 + 防撞人行道护栏 + 路口凸面反光镜 + 斑马线/减速带贴花。

### 2.2 环节一：2D 概念设计（负责审美与结构定义）
* 使用 ChatGPT / Midjourney 输出带有明确结构设计的单体概念图，**严格恪守以下输入铁律**：
  * **角色资产（高度依赖骨骼对称与对齐）**：**必须严格输出正/侧/背无透视正交三视图**（如 Aster 终版三视图），严禁任何动态 pose；
  * **建筑单体与街景道具（硬表面/静态构件）**：**【核心避坑】严禁强制拼凑三视图**！多视图拼图的微小透视误差极易导致 AI 3D 扭曲。必须采用**单张纯白背景、无多余杂物遮挡、45° 俯瞰轴测透视图（Isometric / 3/4 Perspective View）**。Tripo3D 2.0 对单张高清轴测图的神经重构精度与体积感远超拼凑三视图！

### 2.3 环节二：Tripo3D 3D 原生生成（负责曲面与贴图资产化）
* 将制作人审核通过的单体 2D 概念图输入 Tripo3D 2.0，直接导出高精单体 `.glb` 文件；
* 每一件资产都是独立的、结构饱满的完整单体模块（严禁多物体黏连成不可拆分的泥团）。

### 2.4 环节三：Agent 的核心工程职责（负责尺寸标定与引擎装配）
Agent **绝不当下场画画的蹩脚画师，Agent 的核心精力 100% 聚焦于工业级工程整合**：
1. **尺寸标定与地面吸附**：严格执行 1 单位 = 1 米，建筑外立面按 2m/4m 网格基准对齐，底部顶点精准贴合 `Z=0`；
2. **高精度网格规整（Quality-First 策略）**：
   * **【高精先行，LOD后置】**：首发生产阶段**坚决保证模型的高精度与结构饱满度**，彻底打出 31 张参考图的顶级视觉天花板，后期若真机性能有压力再自动化做 LOD 减面优化；
   * 单体建筑保留完整的实体门窗框、挑檐、屋顶瓦脊与外挂落水管（**15,000 ~ 35,000 三角面**）；
   * 高频街景小道具保留物理按键、金属网格、外露螺栓与把手（**3,000 ~ 10,000 三角面**）；
3. **碰撞体与 Prefab 封装（Collision & Prefab Packaging）**：
   * 为建筑和道具生成凸包或简化箱体 `CollisionShape3D`，封装为独立 Godot `.tscn`；
4. **关卡搭建（Level Dressing）**：在沙盒中按 2m/4m 网格模块化拼接，实现滑铲、蹬墙跳与战斗无缝穿行。

为彻底解决“Trim Sheet 模块化工艺”与“Tripo 3D 自由生成”的哲学冲突，本项目确立**四级场景资产制造与装配体系**：

| 层级 | 适用对象 | 制造工艺与数据源 | 贴图与材质策略 | 核心目标与面数预算 |
| :--- | :--- | :--- | :--- | :--- |
| **Tier 1: 地面基础设施** | 柏油马路、坡道、混凝土路沿石、人行道砖、盲道条、斑马线 | **CS2 级 Trim Sheet + 平铺 PBR**<br>（2m/4m 网格吸附，程序化或高精扫描纹理） | 共享 1~2 张 2K PBR 图集（无缝平铺、微湿粗糙度对比） | 保证大面积地面无缝拼接、无接缝走样、零破绽、极低显存 |
| **Tier 2: 核心特色建筑** | 折角便利店、斜屋檐拉面馆、机能公寓立面、二层挑台 | **GPT 立面轴测图 ➔ Tripo3D 生成 ➔ Blender 网格规整**<br>（尺寸严格标定为 2m/4m 整数倍） | 建筑外墙 PBR 图集 + 45° 倒角 + 挑檐走廊结构 | **15,000 ~ 35,000 面**（对标 CS2 物理进深门窗、悬挑露台、独立落水管、多级倒角台阶、真实屋顶瓦片） |
| **Tier 3: 街景高频小道具** | 自动贩卖机、空调外机架、日式垃圾箱、配电柜、雨棚、踏板摩托 | **Tripo3D 原生单体直出 ➔ Blender 规范装配** | 道具独立图集（发光灯箱 Emissive、金属微划痕粗糙度） | **3,000 ~ 10,000 面**（对标 CS2 物理按键、金属散热格栅、外露螺栓与把手，作为独立 Prefab 自由摆放） |
| **Tier 4: 远景天际线** | 远景大厦剪影、层叠住宅群体块、远方山体/铁塔 | **低模体块剪影 + 视差贴花**<br>（单个建筑 50~300 面） | 远景雾化着色器 + 简单发光贴图 | 配合 Godot 4.7 体积雾（Volumetric Fog）营造深邃空间进深 |

## 4. 《明日方舟：终末地》级美术落地规范与图库对照基准

所有生成资产与引擎组装，必须强制对齐 [`asternova/art/references/map_style/`](../../art/references/map_style) 权威图库进行肉眼对照验收：

1. **Tier 1 地面平铺基准（锚定 `cs2_inferno_*.png`）**：
   * 柏油路面、混凝土接缝、人行道砖与盲道，必须达到 CS2 级的无缝拼接与清晰度；
   * 严禁出现模糊拉伸与破面接缝，地面阴角预留贴花（排水口水渍、落叶）。
2. **Tier 2/3 建筑与道具工业机能（锚定 `anime_urban_zzz_*.png` & 终末地设定）**：
   * **几何形体（Silhouette & Bevels）**：严禁平直方块墙！建筑转角采用 45° 切角（Chamfer）、一层外凸 0.8~1.5m 形成挑檐走廊，二层外挂钢结构维修连廊与空调架；
   * **高频烟火气道具**：近景 0~15m 内必须密集分布自动贩卖机、分类垃圾箱、凸面反光镜、水泥电线杆拉线组；
   * **材质表达**：底色克制 + 局部高饱和警示条/发光霓虹灯箱点缀，金属与塑料带有真实微磨损粗糙度。
3. **环境光影与氛围感（锚定 `anime_victorian_dna_*.png`）**：
   * 采用微湿路面 PBR 粗糙度对比，精准反射室内溢出的暖色灯光；
   * 配合 Godot 4.7 Compatibility/Forward+ 体积雾弱化远景，营造极致通透的机能街景。
