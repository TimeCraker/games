# AsterNova 场景与角色工业化生产管线指南（Modular Art & Asset SOP）

> **生效日期**：2026-09-05 起正式生效。  
> **核心宗旨**：彻底废黜“Agent 代码硬搓方块几何体”的歧途，确立**「2D 概念生图 ➔ 3D AI 单体原生生成 ➔ Agent 拓扑组装与引擎装配」**的工业化分工体系；视觉与性能全面对标**《明日方舟：终末地》（Arknights: Endfield）**的高级机能美学与极致性能克制。

## 1. 痛点复盘与核心认知红线

在之前的技术试错中，暴露了严重的“闭门造车”短板，所有进场 Agent **必须绝对恪守以下三条红线**：
1. ❌ **严禁 Agent 用代码手搓场景建筑（严禁火柴盒式白模）**：
   Agent 靠简单的 Cube/Cylinder 和平铺贴图拼出来的房屋，本质是千禧年 PS2 水平的单调积木，毫无设计感与结构剪影，再强的后处理光影也无法弥补几何体本身的拙劣。
2. ❌ **严禁试图用 AI 3D 一键生成整张大地图**：
   AI 3D 工具（如 Tripo3D）目前擅长且仅擅长“单体物体（Props/Buildings）”，一旦整街生成就会塌陷成无法进入、无法行走的实心畸形泥团。
3. ❌ **严禁脱离工业现实的面数自嗨（厘清「场景克制」vs「角色堆料」的双轨标准）**：
   * **行业实测调研数据（2024~2026 次世代二游标杆）**：
     * **《明日方舟：终末地》**：PC/主机端角色实测高达 **80,000 ~ 100,000 三角面**（官方为 Unity 深度重构以承载普通游戏 1.5 倍面数）；移动端约为 40,000 ~ 50,000 面。所谓的“机能低面数”是针对**场景建筑**（中模大倒角 + 平直硬表面 + Trim Sheet + 法线贴花，单体建筑仅需 3k~8k 面），而**角色本身是高规格精模**！
     * **《鸣潮》**：PC 端角色通常在 **90,000 ~ 120,000 三角面**，极致追求长发丝滑分层、机甲细节与多重骨骼形变；
     * **《绝区零》**：角色常态 **35,000 ~ 60,000 三角面**，重点服务于全身全动画（Full Animation）的高频形变与夸张挤压拉伸；
     * **《原神》**：早期移动端妥协产物，常态仅 15,000 ~ 25,000 面（现代动作二游已全面超越此标准）。
   * **AsterNova 权威双轨预算基准（定稿）**：
     * **场景单体（克制极简）**：单体建筑严控在 **3,000 ~ 8,000 三角面**，街景道具 **500 ~ 2,500 三角面**，靠 45° 倒角与 PBR 材质出质感；
     * **角色 Aster（次世代高精）**：PC 旗舰档（120+ FPS）全套总预算确立为 **60,000 ~ 85,000 三角面**（长发 15k~22k、高精面部 8k~12k、服饰与配饰 35k~45k、佩刀 1k~1.5k），彻底告别塑料片廉价低模；LOD1 档自动规整至 **25,000 ~ 35,000 面**。

## 2. 工业化资产生产流水线（Modular Triad Pipeline）

```
┌───────────────────────────┐      ┌───────────────────────────┐      ┌───────────────────────────┐
│   1. 资产规划与 2D 概念设计 │ ──>  │    2. 单体高精 3D 神经生成   │ ──>  │  3. Agent 拓扑组装与实装  │
│   (按 Kit 规划 / GPT生图)  │      │        (Tripo3D 2.0)      │      │     (Blender & Godot)     │
└───────────────────────────┘      └───────────────────────────┘      └───────────────────────────┘
   • 严禁零散出模，按 Kit 套件规划       • 输入纯净概念图生成单体 .glb       • 尺寸标定（2m/4m 格网吸附）
   • 角色：严格正/侧/背三视图            • 产出原生高精雕刻网格与贴图         • 智能 Quad 拓扑与减面
   • 建筑/道具：45° 单张高清轴测图        • 杜绝拼凑畸形，保曲面饱满           • 碰撞体（CollisionShape3D）装配
   • 锚定 map_style 官方参考图库                                         • 街区 Prefab 乐高式组装
```

### 2.1 环节零：套件规划机制（Kit-based Planning，杜绝单件孤岛）
* 严禁无规划地单件零散制作，必须由制作人与主脑先行商讨敲定**「功能套件清单（Asset Kit List）」**，批量推进：
  * **Kit A（街角商铺套件）**：折角便利店主体 + 外挂遮阳棚 + 侧立式发光灯箱招牌；
  * **Kit B（街景高频设施套件）**：双联自动贩卖机 + 分类垃圾桶 + 水泥电线杆拉线组 + 空调挂机组；
  * **Kit C（路面动线套件）**：沥青下坡道 + 防撞人行道护栏 + 路口凸面反光镜 + 斑马线/减速带贴花。

### 2.2 环节一：2D 概念设计（负责审美与结构定义）
* 使用 ChatGPT / Midjourney 输出带有明确结构设计的单体概念图，**严格恪守以下输入铁律**：
  * **角色资产（高度依赖骨骼对称与对齐）**：**必须严格输出正/侧/背无透视正交三视图**（如 Aster 终版三视图），严禁任何动态 pose；
  * **建筑单体与街景道具（硬表面/静态构件）**：**【核心避坑】严禁强制拼凑三视图**！多视图拼图的微小透视误差极易导致 AI 3D 扭曲。必须采用**单张纯白背景、无多余杂物遮挡、45° 俯瞰轴测透视图（Isometric / 3/4 Perspective View）**。Tripo3D 2.0 对单张高清轴测图的神经重构精度与体积感远超拼凑三视图！

### 2.3 环节二：Tripo3D 3D 原生生成（负责曲面、Quad 拓扑、骨骼与 PBR 贴图）
* 将制作人审核通过的单体 2D 概念图输入 Tripo3D 2.0 / Studio，**直接利用其最新工业能力导出高精资产**：
  * **Smart Mesh Quad 拓扑**：在导出面板直接设定目标面数（建筑 1.5w~3.5w 面，角色 6w~8.5w 面，小道具 3k~1w 面），直出规整四边面低模；
  * **Auto-Rigging 自动骨骼**：角色直接生成 Humanoid 骨骼与权重；
  * **PBR 全套贴图**：自带 BaseColor 与 Normal / ORM (AO+Roughness+Metallic) 贴图；
  * 导出通用 `.glb` 或 `.fbx`，彻底免除 Agent 耗时耗力的底层重拓扑算法负担。

### 2.4 环节三：Agent 的核心工程职责（双轨生产与引擎装配）
Agent 核心精力 100% 聚焦于工业级工程整合，场景资产采取**「AI 神经生成 + Agent 程序化脚本」双轨生产模式**：
1. **双轨生产矩阵（因地制宜，效率最大化）**：
   * **轨道 A（AI 神经生成 · 针对复杂造型）**：特色商铺、贩卖机、Vespa 摩托车等具强烈有机与特色设计的单体 ➔ 走 Tripo3D 生成；
   * **轨道 B（Agent 程序化代码搭建 · 针对规律构件与小组件）**：道路路沿石、交通锥、防撞护栏、悬链线空中电缆、长椅等 ➔ 由 Agent 直接编写 Blender Python 脚本，采用**清晰大体块几何 + 纯色/微粗糙度 PBR 材质（类似高级 Low-Poly / 终末地极简机能风）**秒级生成，光影干净利落，零贴图冗余；
2. **尺寸标定与地面吸附**：严格执行 1 单位 = 1 米，建筑外立面按 2m/4m 网格基准对齐，底部顶点精准贴合 `Z=0`；
3. **高精度网格规整（Quality-First 策略）**：
   * **【高精先行，LOD后置】**：首发生产阶段**坚决保证模型的高精度与结构饱满度**，打出 31 张参考图的顶级视觉天花板，后期若真机性能有压力再自动化做 LOD 减面；
4. **碰撞体与 Prefab 封装（Collision & Prefab Packaging）**：
   * 为建筑和道具生成凸包或简化箱体 `CollisionShape3D`，封装为独立 Godot `.tscn`；
5. **关卡搭建（Level Dressing）**：在沙盒中按 2m/4m 网格模块化拼接，实现滑铲、蹬墙跳与战斗无缝穿行。
6. **视觉终极原则（视觉效果第一，不拘泥技术标签）**：
   * 不论采用 PBR、NPR 还是程序化 Flat-PBR，**最终在下午 14:30 晴空光照下，肉眼必须通透、高级、舒服，以 31 张参考图为唯一验收标尺**！

### 2.5 核心定型路线：AI 底模 + 自动化几何手术修补（Surgery & Modular Enhancement）

在 Tier 2 核心建筑（如便利店）与 Tier 3 复杂道具的实战攻坚中，团队探索并定型了工业级的高效闭环管线：**严禁脱离 AI 从零手动堆砌白模（耗时极长且缺乏有机设计感），也坚决禁止直接“裸用”未经治理的 AI 原模**。资产全面采用**「Tripo AI 神经生成底模 + Blender Python 自动化几何手术（Surgery）+ 工业级构件模块化嵌装（Modular Injection）」**：

1. **分工与权重配比**：
   * **Tripo3D 负责 80% ~ 85% 宏观资产**：承担建筑整体体量、外墙有机转折、屋檐悬挑剪影、结构比例与基础 PBR 漫反射/粗糙度纹理；
   * **Agent 脚本手术负责 15% ~ 20% 工程与细节质感治理**：由自动化脚本（如 `surgery_<asset>.py`）执行精准的拓扑切除与物理级构件注入。
2. **根除 AI 生成四大固有硬伤（手术规范）**：
   * 🔪 **切除破碎假玻璃**：AI 生成的门窗玻璃全是扭曲撕裂的三角面，挂载透光着色器必产生畸变与穿模。手术逻辑：精确定位并彻底删除玻璃三角面，程序化嵌装正交铝合金窗框（深灰金属质感 `#2C3138`）与高透双层 PBR 钢化玻璃。
   * 🔪 **剔除扁平 2D 贴纸内景**：AI 习惯在窗内贴一层模糊平面的室内照片贴图，侧角或近景毫无纵深。手术逻辑：剔除内壁假贴纸，打通室内物理空间，嵌装真实 3D 实体货架（Gondola Racks）、彩色分类商品盒与地砖。
   * 🔪 **清除漂浮飞刃与离板杂质（Loose Geometry）**：AI 在招牌与挑檐附近常生成非流形碎面。手术逻辑：利用空间包围盒（AABB）与孤立网格体量过滤器，自动剔除全部悬浮飞刃。
   * 💡 **注入工业级光影外溢**：在室内天花板布设柔和暖白 LED 漫射阵列，在店门口布设向外泼洒的迎宾暖色点光源，夜幕或冷天光下形成极具电影感的冷暖对比与迎宾氛围。
3. **标准化交付范例**：
   * 以折角便利店为样板：`convenience_store_raw.glb` ➔ `surgery_convenience_store_body.py` ➔ 输出商业级零瑕疵 `convenience_store.glb`。后续所有商业建筑（拉面馆、咖啡厅、机能公寓）与高频街景道具均严格复用此手术脚本规范。

## 3. 四级场景资产制造与装配体系

为彻底解决“Trim Sheet 模块化工艺”与“Tripo 3D 自由生成”的哲学冲突，本项目确立**四级场景资产制造与装配体系**：

| 层级 | 适用对象 | 制造工艺与数据源 | 贴图与材质策略 | 核心目标与面数预算 |
| :--- | :--- | :--- | :--- | :--- |
| **Tier 1: 地面基础设施** | 柏油马路、坡道、混凝土路沿石、人行道砖、盲道条、斑马线 | **CS2 级 Trim Sheet + 平铺 PBR**<br>（2m/4m 网格吸附，程序化或高精扫描纹理） | 共享 1~2 张 2K PBR 图集（无缝平铺、微湿粗糙度对比） | 保证大面积地面无缝拼接、无接缝走样、零破绽、极低显存 |
| **Tier 2: 核心特色建筑** | 折角便利店、斜屋檐拉面馆、机能公寓立面、二层挑台 | **GPT 45° 轴测图 ➔ Tripo3D 底模 ➔ 自动化几何手术（切除假玻璃与扁平贴纸，嵌入正交窗框与真实 3D 室内货架）➔ 尺寸规整** | 建筑外墙 PBR 图集 + 铝合金窗框 + PBR 高透玻璃 + 室内暖光 | **15,000 ~ 35,000 面**（对标 CS2 物理进深门窗、悬挑露台、真实 3D 陈列、多级倒角台阶，彻底消灭 AI 塑料感） |
| **Tier 3: 街景高频小道具** | 自动贩卖机、空调外机架、日式垃圾箱、配电柜、雨棚、踏板摩托 | **Tripo3D 原生单体直出 ➔ 几何手术除杂（清除飞刃碎片、嵌装发光灯箱/物理按键）➔ 规范装配** | 道具独立图集（发光灯箱 Emissive、金属微划痕粗糙度） | **3,000 ~ 10,000 面**（对标 CS2 物理按键、金属散热格栅、外露螺栓与把手，作为独立 Prefab 自由摆放） |
| **Tier 4: 远景天际线** | 远景大厦剪影、层叠住宅群体块、远方山体/铁塔 | **低模体块剪影 + 视差贴花**<br>（单个建筑 50~300 面） | 远景雾化着色器 + 简单发光贴图 | 配合 Godot 4.7 体积雾（Volumetric Fog）营造深邃空间进深 |

## 4. 地图规划与美学参考基准（锚定 31 张参考图 · 规划参考而非死板教条）

> **2026-09-06 制作人拍板定案**：[`asternova/art/references/map_style/`](../../art/references/map_style) 31 张权威参考图是**地图规划、氛围营造与美学审美的核心参考锚点，绝非死板的微观教条清单**！建筑与物件不要求机械式硬套所有构件细节，核心是以**大轮廓舒适饱满、有生活烟火气、二次元 PBR 干净通透**为准，坚决避免微观过度堆料导致开发拖沓。**策略定死为：单体逐个击破，慢慢稳步推进。**

1. **Tier 1 地面平铺参考（锚定 `cs2_inferno_*.png`）**：
   * 柏油路面、人行道砖与盲道作为动线基底，追求接缝整洁、清晰通透，避免模糊拉伸与破面。
2. **Tier 2/3 建筑与高频街景道具（参考 `anime_urban_zzz_*.png` & CS2 街景）**：
   * **轮廓与体态（Silhouette & Clean Forms）**：告别单调平直积木，大形轮廓有高低进深与设计感即可，作为地图规划参考，不教条强求每一处必须切角或外挂连廊；
   * **高频烟火气单体（单体逐个生产）**：贩卖机、分类垃圾箱、水泥电线杆、复古摩托车等作为独立单体资产一件件建模实装，丰富街区生活气息；
   * **材质表达**：底色克制干净，金属与塑料具备清爽的二次元 PBR 漫反射与粗糙度表现。
3. **环境光影与通透感**：
   * 下午 14:30 晴空少云，阳光通透无死黑，营造明媚、舒适的日漫日常街区观感。

## 5. 实施推进执行矩阵

| 阶段 | 任务内容 | 负责工具 | 交付与验收基准 |
| :--- | :--- | :--- | :--- |
| **M1: 角色交付** | 摄入 Aster 终版高模，Blender 自动化分件（手臂挥刀、裙摆物理）、Quad 拓扑与 Humanoid 骨骼实装 | Tripo3D + Agent 本地脚本 | Godot 4.7 中挥刀连招与滑铲无穿模，制作人肉眼审核 2K 渲染通过 |
| **M2: 模块化建筑组装** | 依据终末地机能设计，用 Tripo 产出 3 款标准商铺单体与 4 款精细街景道具（贩卖机、遮阳棚等）替代现有方块盒 | GPT 45° 轴测图 + Tripo3D + Agent 组装 | 替换现有平直建筑，关卡轮廓丰富度达到 `map_style` 参考图水准 |
| **M3: 雨夜光影重构** | 在 Godot 4.7 中挂载体积雾、湿润地面 SSR、便利店暖色灯光溢出与冷色雨夜环境 | Agent 场景着色器与调光 | 实机截图完美对标 B 站神级雨夜街角参考图氛围 |
