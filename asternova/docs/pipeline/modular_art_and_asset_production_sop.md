# AsterNova 场景与角色工业化生产管线指南（Modular Art & Asset SOP）

> **生效日期**：2026-09-05 起正式生效，2026-09-16 依据实战全量迭代升级。  
> **核心宗旨**：彻底废黜“Agent 代码硬搓几何体积木”的歧途，确立**「特定造型：2D 概念生图 ➔ 3D AI 神经单体生成（Tripo3D 等） ➔ 几何手术治理」**与**「通用构件与植被：Blender MCP 专业资产库（Poly Haven / CC0）秒级直取」**的双轨工业化分工；代码核心聚焦于**着色器节点装配、微表面 PBR 调校、参数化平面贴花与机位光影渲染驱动**；视觉与性能全面对标**《明日方舟：终末地》（Arknights: Endfield）**的高级机能美学与**《绝区零》（Zenless Zone Zero）**光映广场级都市生活烟火气。

## 1. 痛点复盘与核心认知红线

在之前的实战演进中，团队经历了深刻的技术试错与反思。所有进场 Agent **必须绝对恪守以下四大铁律红线**：

1. ❌ **严禁 Agent 用 Python 脚本手搓立体几何模型（杜绝“圆柱体猫”与“面团球灌木”）**：
   * **客观真实的深层剖析**：Python 脚本在 Blender 中的理论开放上限极高（具备完善的 bmesh、修改器堆栈、几何节点、QuadriFlow 重拓扑与参数化数学 API）。但**为什么 Agent 写脚本建模必定翻车？**
     * 根本原因在于：三维有机雕刻（生物、植被、特色外观）高度依赖空间直觉、多视口实时微调与毫厘级解剖审美。Agent 在无头或脚本编写时缺乏手感与连续视口感知，**极易产生“用代码应付”的怠惰心理**——直接调用 `primitive_cylinder_add` / `primitive_uv_sphere_add` 用几个粗糙的圆柱、圆锥、圆球强行拼接！
     * 这种代码硬凑的产物本质上是简陋的积木玩具（如僵硬的圆柱四肢猫、光滑的绿色面团球灌木），严重缺乏真实的骨骼流线、曲率倒角与有机细节，再强的后处理与灯光也无法挽救模型骨架本身的拙劣。
   * **铁律禁令**：**除简单平面几何外，任何具有立体造型、生物解剖、特色外观的建筑、生物与道具，一律严禁 Agent 使用代码堆叠生成！**
2. ❌ **严禁试图用 AI 3D 一键生成整张大地图**：
   * AI 3D 工具（如 Tripo3D / Rodin）目前擅长且仅擅长“单体物体（Props/Buildings/Characters）”，一旦整街生成就会塌陷成无法进入、无法行走的实心畸形泥团。
3. ❌ **严禁脱离工业现实的面数自嗨（厘清「场景克制」vs「角色堆料」的双轨标准）**：
   * **行业实测调研数据（2024~2026 次世代二游标杆）**：
     * **《明日方舟：终末地》**：PC/主机端角色实测高达 **80,000 ~ 100,000 三角面**；移动端约为 40,000 ~ 50,000 面。所谓的“机能低面数”是针对**场景建筑**（中模大倒角 + 平直硬表面 + Trim Sheet + 法线贴花，单体建筑仅需 3k~8k 面），而**角色本身是高规格精模**！
     * **《鸣潮》**：PC 端角色通常在 **90,000 ~ 120,000 三角面**，极致追求长发丝滑分层、机甲细节与多重骨骼形变；
     * **《绝区零》**：角色常态 **35,000 ~ 60,000 三角面**，重点服务于全身全动画（Full Animation）的高频形变与夸张挤压拉伸；
   * **面数策略（2026-09-10 制作人定案：生成不设上限）**：
     * **AI 生成资产（建筑 / 道具 / 角色）在生成阶段一律直接取最高面数档**，不设人工上限，先打满结构与细节的视觉上限；
     * **兜底链路（后置，不在生成期纠结）**：真机性能有压力时，再自动化跑 LOD 减面 + 三档画质分级；严禁在生成阶段凭面数焦虑预砍细节。
4. ❌ **严禁死黑泥潭式纯噪波路面（严守现代都市铺装与双频微表面）**：
   * 严禁将地面粗暴做成吸收全部光线的死黑纯噪波沥青水坑。都市地面必须拥有规整的建筑拼接秩序感（如大型交错石板）与双频微表面解耦。

## 2. 工业化资产生产流水线（Modular Triad & MCP Pipeline）

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│                                 AsterNova 3D 资产双轨获取架构                           │
└────────────────────────────────────────────────────────────────────────────────────────┘
                                 │
         ┌───────────────────────┴───────────────────────┐
         ▼                                               ▼
【通道 A：特定定制单体（角色/核心建筑）】         【通道 B：高频通用设施与自然生态（长椅/绿化/路灯）】
 1. 2D 概念设计 (GPT 45°轴测 / 三视图)           1. Blender MCP 资产库直取 (Poly Haven / CC0)
 2. AI 神经 3D 单体生成 (Tripo3D 2.0 最高档)      2. 秒级拉取真实 3D 阔叶植株、蕨类与街具
 3. 原生 Quad 拓扑与 PBR 贴图直出                 3. 零等待、零拼凑，自带工业级 PBR 材质
         │                                               │
         └───────────────────────┬───────────────────────┘
                                 ▼
【环节三：Agent 自动化核心工程职责（严禁手搓几何体，专注工程治理）】
 1. 自动化几何手术修补 (Surgery)：切除假玻璃、打通 3D 室内货架、清除飞刃杂面
 2. 着色器节点网络编排 (Shader Nodes)：PBR 双层车漆、TexBrick 规整石板、分频湿润积水
 3. 参数化平面贴花生成 (PIL / Vector Decals)：2K 高精门头招牌、自行车道喷绘、防滑盲道
 4. 环境天光与色彩科学：Poly Haven 2K 真实 HDRI 漫射注入 + AgX 电影级色调映射
 5. 三级多模态诊断收敛流：局部小样快查 ➔ 半分辨率全景 ➔ 1080p 满血终审交付
```

### 2.1 环节零：套件规划机制（Kit-based Planning，杜绝单件孤岛）
* 严禁无规划地单件零散制作，必须由制作人与主脑先行商讨敲定**「功能套件清单（Asset Kit List）」**，批量推进：
  * **Kit A（街角商铺套件）**：折角便利店主体 + 外挂遮阳棚 + 侧立式发光灯箱招牌；
  * **Kit B（街景高频设施套件）**：双联自动贩卖机 + 分类垃圾桶 + 水泥电线杆拉线组 + 空调挂机组；
  * **Kit C（路面动线套件）**：沥青下坡道 + 防撞人行道护栏 + 路口凸面反光镜 + 斑马线/减速带贴花；
  * **Kit D（广场地表与休闲套件）**：规整交错石板地砖 + 现代实木金属长椅 + 同心铸铁井盖 + 阔叶花坛生态。

### 2.2 环节一：2D 概念设计（负责审美与结构定义）
* 使用 ChatGPT / Midjourney 输出带有明确结构设计的单体概念图，**严格恪守以下输入铁律**：
  * **角色资产（高度依赖骨骼对称与对齐）**：**必须严格输出正/侧/背无透视正交三视图**（如 Aster 终版三视图），严禁任何动态 pose；
  * **建筑单体与街景道具（硬表面/静态构件）**：**【核心避坑】严禁强制拼凑三视图**！多视图拼图的微小透视误差极易导致 AI 3D 扭曲。必须采用**单张纯白背景、无多余杂物遮挡、45° 俯瞰轴测透视图（Isometric / 3/4 Perspective View）**。Tripo3D 2.0 对单张高清轴测图的神经重构精度与体积感远超拼凑三视图！

### 2.3 环节二：3D 原生生成与专业资产库采购双通道
1. **通道 A：Tripo3D 3D 原生单体生成（针对特定建筑与专属角色）**：
   * 将审核通过的 2D 概念图输入 Tripo3D 2.0 / Studio，选择**最高面数档**导出；
   * 直出原生规整 Smart Mesh Quad 拓扑与 PBR 全套贴图，导出通用 `.glb`。
2. **通道 B：Blender MCP 专业资产库直取（针对高频通用设施与自然生态）**：
   * 街区长椅、花坛绿化、路灯、配电箱、垃圾桶等通用资产，**优先直接调用 Blender MCP（如 Poly Haven、CC0 资产库）直取**；
   * 严禁 Agent 重新排队生成通用模型，更严禁 Agent 用代码手搓！MCP 直出的植物（如 `calathea_orbifolia_01` 阔叶植株、`fern_02` 蕨类）具备完整的真实叶片法线与双面散射材质，秒级装配。

### 2.4 环节三：Agent 的法定核心工程职责（明确定位：做工程治理，不做低劣捏模）
Agent 核心精力 100% 聚焦于工业级工程整合与真实视效闭环：
1. **严禁越界捏模**：Agent 的代码能力应用于自动化装配与着色器开发，绝不准用于凭空创建有机立体几何；
2. **尺寸标定与网格吸附**：严格执行 1 单位 = 1 米，建筑外立面按 2m/4m 网格基准对齐，底部顶点精准贴合 `Z=0`；
3. **碰撞体与 Prefab 封装**：为建筑和道具生成凸包或简化箱体 `CollisionShape3D`，封装为独立 Godot `.tscn`；
4. **着色器网络与微表面调校**：编写 Cycles / Godot PBR 着色器代码，驱动复杂的 TexBrick 铺装、分频粗糙度与双层清漆；
5. **关卡组装与美学验收**：以真实参考图为唯一验收标尺，肉眼通透、高级、舒服方可通过。

### 2.5 核心定型路线：AI 底模 + 自动化几何手术修补（Surgery & Modular Enhancement）
对于特色建筑（如折角便利店）与复杂道具，全面采用**「Tripo AI 神经生成底模 + Blender Python 自动化几何手术（Surgery）+ 工业级构件模块化嵌装（Modular Injection）」**：
1. 🔪 **切除破碎假玻璃**：精确定位并彻底删除扭曲撕裂的玻璃三角面，程序化嵌装正交铝合金窗框（深灰金属质感 `#2C3138`）与高透双层 PBR 钢化玻璃。
2. 🔪 **剔除扁平 2D 贴纸内景**：剔除内壁假贴纸，打通室内物理空间，嵌装真实 3D 实体货架（Gondola Racks）、彩色分类商品盒与地砖。
3. 🔪 **清除漂浮飞刃与离板杂质（Loose Geometry）**：利用空间包围盒（AABB）与孤立网格体量过滤器，自动剔除全部悬浮飞刃。
4. 💡 **注入工业级光影外溢**：在室内天花板布设柔和暖白 LED 漫射阵列，在店门口布设向外泼洒的迎宾暖色点光源，夜幕或冷天光下形成极具电影感的冷暖对比。

### 2.6 参数化平面贴花与发光标识管线（Decals & Signage Pipeline）
在场景招牌、地面交通标线与公共标识上，**严禁手绘低清贴图，全面确立 Python PIL / 矢量高精贴花管线**：
1. **参数化 2K/4K 贴图生成**：
   * 利用 Python PIL / Vector 脚本，秒级生成抗锯齿加粗排版、自发光遮罩与带有工业包边框架的 2K PNG 贴花（如 `ez_studio_sign_master.png`、`bike_lane_decal.png`、黄色防滑导盲圆点等）；
   * 优势：像素级锐利、无压缩模糊、修改文案或排版仅需毫秒级重新执行脚本，绝对不失真。
2. **正向对齐与法线贴合（Decal Alignment）**：
   * 严防网格 scale 为负或 UV 水平翻转导致的倒字缺陷；
   * 地面贴花贴平地砖表面（微距间隙 `Z = +0.005m ~ +0.008m`），杜绝 Z-Fighting 闪烁。

### 2.7 三级多模态诊断收敛流（Multi-Tier Diagnostic Verification Loop）
吸取以往盲改翻车教训，严格执行三级自查验收：
1. **Tier 1 局部小样快查（320×240 / 640×480）**：针对微观特征（如猫咪面部朝向、耳朵渐变、贴花正反、树叶法线），架设临时局部特写镜头秒级渲染诊断，快速定位隐蔽 Bug，严禁全景盲跑；
2. **Tier 2 全景半分辨率验证（960×540）**：验证全局构图、透视导向线、天光反射与店铺冷暖溢光；
3. **Tier 3 满血终审成图（1080p / 2K）**：所有几何、着色器与光影完全收敛后，开启 Cycles 96 Samples + OpenImageDenoise 输出无瑕疵成品，并与参考图进行同框对比交制作人拍板。**严禁 Agent 自报虚假相似度数值**。

## 4. 地图规划与美学参考基准（吸收《绝区零》生活烟火气与《终末地》冷峻机能）

1. **美学融合准则**：
   * **吸收《绝区零》**：现代机能都市生活烟火气、个性化工业店面（如 EZ STUDIO 工业悬挂箱体）、开阔石板广场秩序与街角随行宠物交互；
   * **融合《终末地》**：冷峻清透的双半球天光、克制洗练的现代建筑微表面、不浮躁的高级灰阶与 AgX 电影级高光收敛，坚决剔除早期劣质网图中过饱和燥热滤镜与脏杂噪点。
2. **环境光照黄金标准**：
   * 全面引入 **Poly Haven 2K/4K 真实都市阴天 HDRI（如 `round_platform`）** 作为环境漫射核心，配合 **AgX 模式（Medium High Contrast）**，形成漫射天光柔和、接触阴影扎实、高光自然滚降收敛的顶级二游画质。
