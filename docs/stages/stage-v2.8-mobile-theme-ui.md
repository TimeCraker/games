# Stage v2.8 — 动漫主题与移动端游戏 UI

## 目标
根据真实手机截图，将主页个人照片主题替换为两张动漫原图；消除游戏内顶栏重叠并压缩移动端信息密度；为 GLM-5.2 准备独立的性能与特效优化实施计划。

## 设计判断
- 主页不再展示个人照片或个人照片方块。
- 桌面端使用横向星空动漫壁纸，移动端使用竖向双人动漫壁纸。
- 游戏进行中隐藏全局工具栏，只显示关卡标签与暂停按钮。
- 移动端删除重复的关卡名称卡，目标/HUD/棋盘顺序紧凑排列。
